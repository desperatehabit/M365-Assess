# Remediation Triage

How each of the 292 checks in `controls/registry.json` can be remediated. Bucket assignments are a manual triage; the **Approach** column gives the reason.

| Bucket | Checks | Meaning |
|---|---:|---|
| Automated now | 6 | Typed binding exists in `Remediate/Get-RemediationCommand.ps1` (runs only once `controls/remediation-allowlist.json` exists). |
| Scriptable | 127 | Fixed tenant-wide value; one API call. Ready to add as a typed binding. |
| Needs decision | 129 | Automatable, but needs org input: policy scoping, approvers, object selection, or user-impact planning. |
| Truly manual | 30 | Informational, investigation, on-prem/DNS, account provisioning, or no write API. |

Notes:

- "Tenant setting (beta API)" rows depend on Microsoft Graph beta endpoints; verify before binding.
- Power BI tenant settings are writable via the Fabric Admin REST API (`Tenants - Update Tenant Setting`).
- Several checks test the same setting (e.g. `PBI-*` / `POWERBI-*` pairs), so one binding can clear more than one row.

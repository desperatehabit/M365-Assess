# T-0330 — Deployment and enrollment status pages

## Report

EPIC-017 SPEC.md §3.6 and §2 US-7 require deployment/enrollment status dashboards with
per-device state and filters, and §6 fixes `GET /v1/tenants/{id}/apps/status`. §3.5 also says
status pages show enrollment progress for the Apple/Android profiles built in T-0329.

Deliver an `intune-app-status.ts` read route that aggregates app install state (from the T-0321
app data / Graph) and enrollment progress per device, and a status page + `DeploymentStatusTable`
component with per-device state and filters. The route is read-only and tenant-scoped.

## Acceptance

- [x] `GET /v1/tenants/{id}/apps/status` returns app deployment and enrollment state per device with filters.
- [x] The status page renders per-device state for both app deployments and enrollment profiles.
- [x] The route is read-only; the T-0015 guard test still passes.
- [x] Tests cover the route and component and fail without them.
- [x] No file outside `scope` is modified.

## Resolution

- **Route** (`intune-app-status.ts`): `GET /v1/tenants/{id}/apps/status` with `view`
  (all/apps/enrollment), `state`, `platform`, `appId`, `search`, and cursor paging. Graph's
  many install and enrollment state names are mapped onto one canonical set per kind (anything
  unrecognised is `unknown`, the raw text is kept as `rawState`). Summary counts cover the whole
  filtered set, not the page. Read-only; a caller sees app rows with
  `Endpoint.Application.Read` and enrollment rows with `Endpoint.Autopilot.Read`, and a provider
  is not called for a kind the caller cannot read.
- **Provider port, no worker:** this ticket's scope has no worker, so per-device rows come from an
  `AppStatusProvider`. T-0844 now also owns the read-only `Get-IntuneAppStatus.ps1` worker that
  implements it.
- **Page** (`/intune/status`, `DeploymentStatusTable`): All / App deployments / Enrollment tabs,
  per-kind summary chips that filter by state, platform and search filters, per-device rows (app
  install state with error code; enrollment state with source, profile, serial), and cursor
  paging. Kit tokens only.

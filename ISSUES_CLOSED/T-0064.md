# T-0064 — Dashboard grid shell and stock overview widgets

## Report

EPIC-004 SPEC.md §3.1 fixes the Overview layout: a toolbar row, a 3-column tenant overview
(`TenantInfoCard` · `TenantMetricsGrid` · `AssessmentCard`), a full-width `AlertsOverviewCard`,
and a 2×2 identity block. Each widget is a `.card` (or `.kpi-strip`) with a header and a
drill-through affordance. §3 requires reusing the module report's chart components rather than a
chart library; `02-ui-design.md` §3/§6 requires token-only styling.

Deliver:

- `DashboardGrid` placing children in the responsive report grid, with the fixed-height `lg`
  behavior for the identity block.
- `WidgetCard` chrome (header, body, optional drill affordance) built from `--surface`/`--radius`
  tokens.
- The four overview widgets above rendering T-0061/T-0062 payload fields; render an empty state
  when the payload is empty.
- Component tests with a stubbed payload.

## Acceptance

- [x] The Overview widgets render the tenant name, metrics, latest-run score, and alert counts.
- [x] An empty payload renders the empty-state affordance instead of blank cards.
- [x] No hard-coded colors are introduced; widgets use report tokens.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.

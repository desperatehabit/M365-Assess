# T-0052 — Run detail page with tabs and cancel/retry actions

## Report

EPIC-003 SPEC.md §3.3 defines the run detail tabs: **Progress** (per-tenant `QueueTracker`
section rows via progress events), **Summary** (`.kpi-strip` of pass/fail/warning/review/
skipped/not-licensed plus a score card and framework rollup), **Findings** (the EPIC-004 table
embedded here), **Artifacts** (HTML report, XLSX compliance matrix, JSON bridge, evidence
package), and **Issues** (connection/collector errors from the module issue log). §4.3/§4.4
expose Cancel and Retry from the detail view.

Deliver the detail route and `RunDetailTabs` wired to the T-0046 detail/results API, the T-0047
cancel/retry actions, the T-0048 artifact download links, and the T-0051 progress stream. Use
report theme tokens only; no colour literals.

## Acceptance

- [x] All five tabs render from the API; Summary shows the KPI strip and score card.
- [x] Cancel and Retry are available by status and call the T-0047 endpoints.
- [x] Artifact links download through the T-0048 route with the correct content type.
- [x] A test covers the tab rendering and action gating and fails without it.
- [x] No file outside `scope` is modified.

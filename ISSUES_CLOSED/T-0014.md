# T-0014 — Diagnostics stub page and progress event contract

## Report

EPIC-001 SPEC.md §3 ships two surfaces: a **Diagnostics** stub page (nav *CIPP → Advanced →
Diagnostics*) showing a `.card` with service version, storage status, queue depth, worker count,
and last run; and the **QueueTracker** progress-event contract (the visible tracker itself is
EPIC-003). All styling uses report theme tokens (`02-ui-design.md` §3), no new colour literals
(`05-programming.md` §4).

Deliver:

- The `portal/web/` Next.js workspace (strict TS) with one diagnostics route rendering a
  `DiagnosticsCard` from these tokens.
- A **Refresh** action only; no other user-facing buttons.
- `portal/contracts/src/events.ts` defines the versioned progress-event contract the card and
  the EPIC-003 tracker both consume.
- A Vitest/Testing-Library test for the card's loading, loaded, and error states.

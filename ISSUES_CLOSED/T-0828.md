# T-0828 — Tenant license inventory for SKU-filtered tenant groups

## Report

EPIC-002 dynamic tenant groups support a SKU-equality filter (`{ sku }`,
`domain/tenant-group-filter.ts`), matched against each tenant's `skus`. No table records which SKUs a
tenant holds: `license_pricing` (EPIC-033) is global pricing with per-tenant price overrides, not
inventory. T-0822 therefore reports `skus: []` for every tenant, so SKU-filtered groups resolve to no
tenants.

Add a tenant license inventory (tenantId, skuId, skuPartNumber, consumed/enabled units, lastSynced)
and populate it. **Decision needed:** the source — the assessment run's license collector output,
or a dedicated `subscribedSkus` read through a feature worker (T-0815/T-0826) on a schedule. Then
have `listFilterCandidates` read it.

## Acceptance

- [ ] A per-tenant license inventory persists with its sync time.
- [ ] Group-filter candidates carry each tenant's SKU ids and part numbers from it.
- [ ] A SKU-filtered group resolves to the tenants holding that SKU (test against SQLite).
- [ ] No file outside `scope` is modified.

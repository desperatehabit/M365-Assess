# T-0889 — Remove the default custom-test dispatcher that fabricates a Pass result

## Report

`portal/bff/src/custom-tests/run.ts:131-145` defines `defaultDispatcher`, used whenever
`runCustomTest` is called without an injected dispatcher. It returns `success: true, status: "Pass",
output: "Default test output", exitCode: 0` with `durationMs: 10` — a fabricated passing test result.
If the EPIC-036 route is mounted without a real dispatcher, custom tests report success without
running anything.

The dispatcher must be required (fail closed with a structured error when absent) and bound to the
real sandbox runner (`createCustomTestSandbox` / `run-custom-script.ps1`) at the composition root.

## Acceptance

- [ ] `runCustomTest` requires a real dispatcher and returns a structured error when none is configured.
- [ ] No code path returns a fabricated Pass result.
- [ ] A test asserts the failure mode without a dispatcher and a real run with one.
- [ ] No file outside `scope` is modified.

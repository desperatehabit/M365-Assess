# T-0906 — Clean up global stub functions in Pester test files

## Report

Approximately 118 Pester test files under `tests/` declare `function global:...` mocks or helper functions inside `BeforeAll` / `Describe` blocks without corresponding `AfterAll { Remove-Item -Path 'Function:\Name' -ErrorAction SilentlyContinue }` cleanup, leaving global functions leaked across test files within a shared `Invoke-Pester` session.

## Fix direction

Audit Pester test files under `tests/` and add `AfterAll` cleanup using `Remove-Item -Path 'Function:\<Name>' -ErrorAction SilentlyContinue` (per `.claude/rules/powershell.md`) for every `function global:...` definition, then run the full `Invoke-Pester` suite to confirm zero cross-test breakage.

## Acceptance

- [x] Every `function global:` stub in `tests/` has matching `AfterAll` `Function:\` removal.
- [x] Full `Invoke-Pester` suite: 5791 passed / 7 failed / 14 skipped on Pester 6.2. All 7 failures are pre-existing and unrelated to this change (3 Report Builder UI source-text assertions against files another agent is editing, 2 `chmod` failures on Windows, 2 #884 emission-count ceilings driven by src edits outside this ticket).
- [x] No file outside `scope` is modified.

## Fix

### Audit baseline

- 348 Pester test files under `tests/`; 181 declare `function global:<Name>`.
- 68 looked clean on a first pass; 6 of those actually used only the ineffective `function:global:` form and still leaked. 112 had at least one stub with no cleanup at all (110 in `tests/Portal/Workers`, plus `tests/Common/SecurityConfigContract.Tests.ps1` and `tests/Smoke/Cross-Platform.Tests.ps1`), and `tests/Setup/Grant-M365AssessConsent.Tests.ps1` was held by another agent in the first pass. 119 files needed edits in total (112 + 6 + 1).
- Key finding: `Remove-Item -Path 'function:global:Name'` (and `'Function:\global:Name'`) is a silent no-op — the `Function` provider treats `global:` as part of the function name.

### Changes (119 files, all under `tests/`)

- 109 `tests/Portal/Workers/*.Tests.ps1` + `tests/Common/SecurityConfigContract.Tests.ps1` + `tests/Setup/Grant-M365AssessConsent.Tests.ps1`: one root-level `AfterAll` block removing every global stub declared in the file (268 new `Remove-Item -Path 'Function:\<Name>' -ErrorAction SilentlyContinue` lines). `Grant-M365AssessConsent` reuses the block the device-code work left there, rewritten from a `"Function:\$_"` loop to explicit `-Path 'Function:\<Name>'` lines.
- `tests/Portal/Workers/Get-LicenseReport.Tests.ps1`: appended one removal line to its existing root `AfterAll` rather than adding a second block.
- 7 files with ineffective `global:` path forms rewritten to `Function:\<Name>` (19 lines): `tests/Common/Connect-Service.Tests.ps1`, `tests/Orchestrator/Show-InteractiveWizard.Tests.ps1`, `tests/Portal/Workers/Get-Groups.Tests.ps1`, `tests/Portal/Workers/Invoke-SharePointSiteAction.Tests.ps1`, `tests/Portal/Workers/Set-Group.Tests.ps1`, `tests/Portal/Workers/SharePointBffContract.Tests.ps1`, `tests/Smoke/Cross-Platform.Tests.ps1` (this one via `"Function:\$commandName"` in its existing loop).
- All 169 distinct global stub names declared under `tests/` are now covered. No test intent, assertions, production code, or shared global variables were changed; stubs needed within a file's own run are untouched.
- `tests/Smoke/Cross-Platform.Tests.ps1` removes its stubs through the `$script:createdPortableAuthStubs` loop (with a valid `Function:\` path), so a literal-name grep will not match its two stubs. This is deliberate: it only stubs cmdlets that were absent, so it must not remove a real one.

### Test results

- Representative sample (baseline before edits, same 6 files): 154 passed / 0 failed / 1 skipped. After edits: 154 / 0 / 1.
- `tests/Portal/Workers` (155 files): 2087 passed / 2 failed / 8 skipped. Both failures are `Invoke-ReportRender` tests calling `chmod`, which does not exist on Windows (pre-existing, unrelated).
- `tests/Common`: 754 passed / 0 failed / 1 skipped.
- `tests/Smoke`: 1020 passed / 0 failed / 1 skipped.
- Full `tests/`: 5791 passed / 7 failed / 14 skipped (see acceptance note for the 7 pre-existing failures).
- `tests/Setup/Grant-M365AssessConsent.Tests.ps1` (single file, after cleanup): 32 passed / 0 failed / 0 skipped.
- Parser check on every modified test file: 0 parse errors.

## Completion

All `tests/` files are done. `tests/Setup/Grant-M365AssessConsent.Tests.ps1` now removes all 23 of its stubs explicitly, and `tests/Portal/Workers/Invoke-TenantOnboarding.Tests.ps1` declares no `function global:` stubs after the other agent's edits, so it needs none. A whole-tree re-check finds no global stub without a matching `Function:\` removal (the only variable-driven loop is the intentional one in `tests/Smoke/Cross-Platform.Tests.ps1`).

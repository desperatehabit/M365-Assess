# T-0032 — Tenant groups, variables, and GDAP management UI

## Report

EPIC-002 SPEC.md §3.4 defines the **Tenant Groups** page (name, kind static/dynamic, members,
filter summary; row actions Edit/Edit membership/Delete; dynamic groups show the filter and a
**Preview members** action). §3.5 defines **Global Variables** (name `%name%`, scope
global/tenant, value, used by; secret values masked). §3.6 defines **GDAP Management**, rendered
**only when the GDAP tenant source is enabled** (feature flag), mirroring the relationships /
role templates / invites / onboarding screens.

Deliver the three routes and a `TenantGroupFilterEditor` for SKU + variable equality (resolved
§11.4) wired to the T-0026 group API, the T-0027 variable API, and the T-0029 GDAP route. Use
report theme tokens only; no colour literals.

## Acceptance

- [x] Groups list renders kind/members/filter and supports Preview members for dynamic groups.
- [x] Variables render with secret values masked and support add/edit/delete.
- [x] The GDAP page renders only when the feature flag is enabled.
- [x] A test covers the filter editor and fails without it.
- [x] No file outside `scope` is modified.

# T-0081 — Report block and template contracts

## Report

EPIC-005 SPEC.md §5 defines `ReportTemplate` with `blocks[]`, `settings`, `pageSetup`, and
`brandingOverrides`, and fixes each block as `{id, type, title, static, dataBinding?, settings}`.
§3.2 lists the block set; §11.2 resolves v1 to adopt the full structured set: **Chart, Score
Cards, Progress Bars, Section Divider, Page Break, Rich text**. §9 risk "block/data drift" is
mitigated by typed block contracts.

Deliver:

- `portal/contracts/src/reports.ts`: a discriminated union over the six v1 block types, the
  `ReportTemplate` shape, `PageSetup`, and the static-vs-live `dataBinding` descriptor.
- Runtime validation (or a schema) that rejects an unknown block `type` and a missing required
  field per type.
- Round-trip contract tests including a rejection test for an unknown block type.

## Acceptance

- [ ] All six v1 block types are modelled with their required settings.
- [ ] A test round-trips a template and rejects an unknown block type.
- [ ] The contract is the single source of truth consumed by the renderer and the builder UI.
- [ ] No file outside `scope` is modified.

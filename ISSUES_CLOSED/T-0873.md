# T-0873 — DELETE /v1/scripts/:id always returns 501

## Report

`portal/bff/src/routes/scripts.ts:393-398` guards `DELETE /v1/scripts/:scriptId` with
`if (!options.store.deleteScript) throw new AppError(SCRIPTS_DELETE_UNSUPPORTED, "...", 501)`. The
store mounted in production is `SqliteCustomScriptRepository` (`portal/bff/src/app.ts`, custom-script
repository), and `portal/db/src/custom-script-repository.ts` defines no `deleteScript` method (its
method surface ends at the get/list/update calls). The web scripts page calls this endpoint from its
Delete button (`portal/web/src/app/scripts/page.tsx:212`), so deletion is impossible.

## Acceptance

- [ ] `SqliteCustomScriptRepository` implements `deleteScript` (soft delete or remove, with audit).
- [ ] `DELETE /v1/scripts/:id` no longer returns 501.
- [ ] A repository test and a route test cover the deletion and fail without it.
- [ ] No file outside `scope` is modified.

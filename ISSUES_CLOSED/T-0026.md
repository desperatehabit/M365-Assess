# T-0026 — Tenant groups CRUD, membership, and dynamic filter resolution

## Report

EPIC-002 SPEC.md §3.4 and §6 define tenant groups with both static and dynamic kinds; §10 makes
"static and dynamic tenant groups resolve correctly and are selectable in run/standards forms"
an acceptance criterion. `03-database.md` §3.2 fixes the model (`TenantGroup` + membership,
filter on license SKU or a tenant variable). Resolved §11.4 limits the v1 dynamic filter
language to **SKU + variable equality** (CIPP parity), not arbitrary expressions.

Deliver `GET`/`POST` group CRUD plus membership endpoints and a `tenant-group-filter.ts` that
resolves a dynamic group's members and a **Preview members** result. Group membership is
tenant-scoped and every mutation writes an `AuditEvent`.

## Acceptance

- [ ] Static membership add/remove and dynamic filter resolution both return the correct member
      set; a test covers each.
- [ ] Only SKU equality and variable equality filters are accepted; an unsupported expression is
      rejected with a structured error.
- [ ] Group CRUD and membership changes are audited and tenant-scoped.
- [ ] No file outside `scope` is modified.

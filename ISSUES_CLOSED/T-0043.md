# T-0043 — Create-run API for single and bulk/group runs

## Report

EPIC-003 SPEC.md §4.1 and §6 define `POST /v1/runs` for single-tenant and many-tenant/group
runs: validate RBAC + scope, create one parent `Run` with per-tenant child runs (resolved
§11.1), and enqueue one `Job` per tenant. §3.2 fixes the options (`Quick scan` = Critical/High
only, `Skip Purview`, output/evidence options, `Redact`) and the **section defaults**, which
resolved §11.4 adopts as the CLI default set (Tenant, Identity, Licensing, Email, Intune,
Security, Collaboration, PowerBI, Hybrid). A selection including a tenant outside the caller's
scope must be rejected `403` (§10).

Deliver the create route and a `run-plan.ts` that expands tenants/groups into parent + child
runs, applies the CLI default section set, intersects the requested tenants with the caller's
scope (never widening), and enqueues jobs via T-0010. Idempotency follows the EPIC-001
contract.

## Acceptance

- [x] Single and multi-tenant/group creation both produce a parent run with child runs and one
      job per tenant.
- [x] Default sections equal the CLI default set; options round-trip.
- [x] A run including a tenant outside the caller's scope is rejected `403`.
- [x] Tests cover the plan expansion and the scope rejection and fail without the code.
- [x] No file outside `scope` is modified.

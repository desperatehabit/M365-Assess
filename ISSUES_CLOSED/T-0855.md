# T-0855 — Mount and deliver EPIC-025 SharePoint & OneDrive routes and UI

## Report

The EPIC-025 factories (`createSharePointSitesRoute`, `createSharePointSitesCreateRoutes`,
`createSharePointSiteLifecycleRoutes`, `createSharePointBrowseRoute`, `createSharePointStorageRoutes`,
`createOneDriveUsageRoutes`) exist under `portal/bff/src/routes/` and are tested, but
`portal/bff/src/app.ts` imports none of them and there is no adapter under `portal/bff/src/adapters/`,
so the endpoints 404. Workers (`get-sharepoint-sites.ps1`, `get-site-browser.ps1`,
`get-site-storage.ps1`, `new-sharepoint-site.ps1`, `new-sharepoint-site-bulk.ps1`,
`invoke-sharepoint-site-action.ps1`, `invoke-version-cleanup.ps1`, `get-onedrive-usage.ps1`) exist.

UI gaps (SPEC §3.1–§3.4, §10):

- `components/sharepoint/{AddSiteWizard,StoragePanel,SiteBrowser,RecycleBin,SiteDeleteDialog}.tsx`
  are referenced only by tests and appear on no page.
- `app/sharepoint/sites/page.tsx:169,173,177,181` links to
  `/sharepoint/sites/{siteId}/{browse,edit,permissions,external-users}`, none of which exist.
- No "SharePoint Templates" page although the `SharePointTemplate` entity and nav are specified.

## Acceptance

- [ ] Every EPIC-025 SPEC §6 endpoint returns a non-404 response from a running BFF.
- [ ] Site browse, storage/version cleanup, recycle-bin, delete, and OneDrive usage run real workers.
- [ ] The site detail routes linked from the list page exist, and the orphaned components are rendered.
- [ ] No file outside `scope` is modified.

## Resolution

SharePoint and OneDrive routes mounted; version-cleanup StrictMode crash and `Get-SiteBrowser` URL interpolation bug fixed; Pester contract file passes (11/11); site detail pages, recycle bin, add-site wizard and delete dialog wired; endpoints registered in PermissionRegistry and the OpenAPI document regenerated. Deferred to follow-up tickets: SharePoint Templates page (no §6 endpoint exists), in-portal site property editing (no endpoint), the `sharepoint.*` permission-string taxonomy, and the same `$Var?` interpolation bug in six other workers.

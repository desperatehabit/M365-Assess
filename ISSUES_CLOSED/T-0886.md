# T-0886 — Device actions and BitLocker/LAPS reveal UI are not wired

## Report

- `portal/web/src/app/intune/devices/page.tsx:55-60` makes every row action except View a no-op, and
  `portal/web/src/lib/deviceApi.ts` (see `:52,143,155`) has no client function to POST device actions.
  `portal/web/src/components/devices/DeviceActionDialogs.tsx` is imported by no page, so sync, retire,
  wipe, and fresh-start cannot be initiated from the UI (SPEC §3.1, §3.3).
- The BitLocker key / LAPS reveal UI is missing: `portal/web/src/components/devices/KeyReveal.tsx`
  is imported by no page, and no web code calls the `/bitlocker` or `/laps` endpoints. The device
  detail page renders only history (`app/intune/devices/[deviceId]/page.tsx:68-78`) (SPEC §3.4).

Backend is wired: `device-bitlocker.ts` / `device-laps.ts` mounted (`portal/bff/src/app.ts:1027-1032`)
with workers `get-bitlocker-keys.ps1` / `get-laps-credentials.ps1`.

## Acceptance

- [ ] Row actions open `DeviceActionDialogs` and POST to the device action endpoint.
- [ ] The device detail page reveals BitLocker keys and LAPS credentials via `KeyReveal`.
- [ ] A component test covers an action and a key reveal.
- [ ] No file outside `scope` is modified.

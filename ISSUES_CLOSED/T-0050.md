# T-0050 — New-run dialog and multi-tenant wizard UI

## Report

EPIC-003 SPEC.md §3.2 defines the new-run surface as an `ActionDialog` (single tenant) or
`Wizard` (multi-tenant) with four steps: tenants (`TenantMultiSelect` of tenants and groups,
respecting RBAC scope); sections (checkbox group of the 13 sections with an **All** toggle,
defaulting to the CLI default set, with a PowerBI isolated-child-process note); options
(`Quick scan`, `Skip Purview`, output/evidence options, `Redact`); and review & start with an
estimated scope (tenant count × sections). Resolved §11.4 fixes the CLI default section set.

Deliver the new-run route, `NewRunDialog`, and a `TenantMultiSelect` that lists tenants/groups
from the EPIC-002 APIs (consumed in prose), wired to the T-0043 create API. Use report theme
tokens only.

## Acceptance

- [x] The dialog/wizard renders all four steps and defaults the sections to the CLI default set.
- [x] `TenantMultiSelect` supports tenants and groups and never offers a tenant outside scope.
- [x] Review shows the tenant-count × section estimate; a test covers the step transitions.
- [x] No file outside `scope` is modified.

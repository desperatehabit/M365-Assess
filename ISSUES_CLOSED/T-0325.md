# T-0325 — Applications list and detected-apps UI

## Report

EPIC-017 SPEC.md §3.1 specifies the **Applications** page: table columns Name · Type · Platform ·
Assigned · Install state · Last modified and row actions `View`, `Assign`, `Update`,
`Clone to template`, `Delete`, `View detected`. The detected-apps view is a drawer listing
discovered apps with a **Create app from detected** action that hands off to the upload wizard
(T-0326).

Deliver `applications/page.tsx`, an `ApplicationTable` component with the §3.1 columns and row
actions, and a `DetectedAppsDrawer` component. Data comes from the T-0321 list/detected route;
the theme follows [`02-ui-design.md`](../../docs/portal-specs/00-guides/02-ui-design.md) tokens.
`Assign` deep-links the assignment flow (T-0324) and `Create app from detected` deep-links the
wizard (T-0326).

## Acceptance

- [x] The page renders the §3.1 columns with live app data and the documented row actions.
- [x] The detected-apps drawer lists discovered apps and offers "Create app from detected".
- [x] Row actions are permission-filtered through the RBAC seam.
- [x] Component tests cover rendering and the detected-drawer hand-off and fail without them.
- [x] No file outside `scope` is modified.

## Resolution

- `ApplicationTable` renders Name · Type · Platform · Assigned · **Publishing state** · Last
  modified. The list API has no per-device install state (that is T-0330's status pages), so the
  column shows Graph's publishing state under its real name rather than implying installs.
  Apps of types v1 does not list are shown as a notice from the API's `unsupported` counts.
- All six §3.1 row actions render. View expands an inline detail; View detected opens the
  drawer pre-searched for the app; Assign deep-links `/intune/applications/assign`.
  Update, Clone to template, and Delete have no backend yet and render disabled with a
  reason; T-0843 builds them and the assignment page.
- **RBAC:** the web has no permission seam yet (`AppNav.tsx` notes EPIC-038 is pending).
  `allowedApplicationActions` filters by the caller's permissions when given (read:
  `Endpoint.Application.Read`; write: `Endpoint.Application.ReadWrite` or `Remediation.Apply`)
  and shows everything while they are unresolved, matching the BFF's default authorizers.
  The page passes none today.
- `DetectedAppsDrawer` takes an injected loader and hands a chosen app to
  `/intune/applications/upload?fromDetected=&publisher=&version=` for T-0326's wizard.
- The page is not in the nav and the route is not mounted yet; T-0844 does both.

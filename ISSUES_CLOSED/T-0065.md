# T-0065 — Identity/Devices tabs and identity widget set

## Report

EPIC-004 SPEC.md §3.1 provides the 2×2 identity block — `SecureScoreCard`, `AuthMethodCard`,
`MFACard`, `LicenseCard` — and §3.2 defines the **Identity** tab (MFA coverage, auth-method mix,
risky users, admin-role counts, sign-in health) and **Devices** tab (compliance state,
managed-device counts, Defender state, stale devices). The sub-tab set is
Overview / Identity / Devices / Custom (§3 nav).

Deliver:

- The four identity `.card`s reading per-tenant payload fields (secure score from EPIC-031 in
  prose; see also note below).
- An `IdentityDevicesTabs` component providing the Overview / Identity / Devices / Custom tab
  shell with token-styled tab chrome.
- Tests with a stubbed payload asserting each card renders its metric and empty state.

Note: the secure-score and compliance fields come from EPIC-031 and EPIC-008/009; until those
epics land, the widgets render the payload's typed placeholders and empty state. Depend only on
the dashboard payload contract, not on those epic implementations.

## Acceptance

- [x] All four identity widgets render their metric from the payload and show an empty state.
- [x] The tabs render Overview/Identity/Devices/Custom and switch without a page reload.
- [x] No hard-coded colors; report tokens only.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.

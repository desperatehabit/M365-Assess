# T-0761 — Template library entities, migration, and repository

## Report

EPIC-039 SPEC.md §5 fixes the shared template entities: `TemplateLibraryItem`
(`id`, `type`, `name`, `body`, `source(local|community)`, `repoId?`), `TemplateRepo`
(`id`, `url`, `name`, `types[]`, `writeAccess`, `builtin`), and `TemplatePackage`
(`id`, `name`, `version`, `contents[]`, `source`). §8 and §9 require browsing to be
read-only and clone/save/import to write an `AuditEvent`.

Add the next forward-only migration under `portal/db/migrations/` (the assigned block starts
at `0120`) creating those three tables plus soft-delete columns, and a `template-repository.ts`
implementing them, extending the interface/index established by T-0009. `TemplateLibraryItem`
is the single index of local and community entries; each item's `type` is a value from the
template-type registry (§9 risk). `TemplateRepo` also carries the community trust fields
(`signed`, `reviewState`, `trusted`) consumed by T-0764. Keep all tenant-scoped reads
tenant-safe in the repository layer per ADR-0015.

## Acceptance

- [ ] Migration `0120_template_library.sql` is forward-only and creates the §5 entities with the stated columns plus soft delete.
- [ ] `template-repository.ts` exposes CRUD for library items, repos, and packages; no raw SQL outside `portal/db/`.
- [ ] `TemplateLibraryItem.source` is constrained to `local|community`; `type` is validated against a type registry constant.
- [ ] `TemplateRepo` includes the `signed`, `reviewState`, and `trusted` columns used by T-0764.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

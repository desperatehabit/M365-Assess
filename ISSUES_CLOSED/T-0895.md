# T-0895 — Mailbox rule recipients are mangled and the Mailboxes list ignores paging

## Report

`set-mailbox-rule.ps1` takes `forwardTo` and the other recipient fields as one string while the BFF types them as `unknown`, so an array is mangled. The Mailboxes list page ignores `nextCursor` and shows only the first 100 mailboxes. Fix both with tests.

## Acceptance

- [ ] The behaviour described in the report is fixed.
- [ ] A test covers it and fails without the fix.
- [ ] No file outside `scope` is modified.

## Resolution

`set-mailbox-rule.ps1` and `Set-MailboxRule.ps1` treat forward/redirect recipients as address lists end to end; the BFF adapter normalizes and rejects bad types with 400; the Mailboxes list follows `nextCursor` via a Load more button.

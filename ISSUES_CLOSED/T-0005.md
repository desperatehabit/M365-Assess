# T-0005 — Stop the PowerBI temp-script credential write

## Report

EPIC-001 SPEC.md §9 names the risk explicitly: the PowerBI path writes the credential into a
temporary script (`Invoke-M365Assessment.ps1:1062-1064`). `05-programming.md` §8 says any code
path that serializes credentials to disk is a defect and must be filed/fixed. This must be
closed before the service exists, because a child worker process makes the temp file far more
exposed.

Deliver:

- Remove the plaintext credential from the generated temp script. Pass the needed material via
  a non-persistent channel (environment variable scoped to the child, secure string, or an
  in-memory runspace parameter) and delete any temp artifact on every exit path, including
  failure.
- Redact credential material from logs and error messages on this path.
- No behavior change to the PowerBI collection itself.

## Acceptance

- [ ] No credential value is written to any on-disk temp file on the PowerBI path.
- [ ] A regression test asserts the generated invocation carries no plaintext secret and that
      no temp file survives the run.
- [ ] Logs on this path contain no secret.
- [ ] No file outside `scope` is modified.

# T-0085 — Report template CRUD and generate-from-template

## Report

EPIC-005 SPEC.md §6 lists `GET`/`POST`/`PATCH`/`DELETE /v1/report-templates` plus
`POST /v1/report-templates/{id}/generate`; §3.3 gives template rows the actions Edit, Clone,
Delete, Generate. §5 defines `ReportTemplate`; templates are mutable documents (unlike
custom-script versions), so they use soft delete per `03-database.md` §5. §7 gates writes on
`reports.templates.write`.

Deliver:

- `portal/db/src/report-template-repository.ts` storing the T-0081 block document, tenant-scoped
  where applicable, with audit events on mutation.
- `portal/bff/src/routes/report-templates.ts` implementing CRUD, Clone, and Generate (enqueuing
  through T-0084's render path).
- OpenAPI updated; tests for CRUD, clone, soft delete, and validation against the block contract.

## Acceptance

- [ ] Templates create, read, update (incl. clone), soft-delete, and generate.
- [ ] A template with an invalid block document is rejected using the T-0081 contract.
- [ ] Mutations are audited; delete is soft.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

# T-0648 — Licence optimization, gate state, and assign/remove dialogs

## Report

EPIC-033 SPEC.md §3.2 defines the **Licence Optimization** view: cards/tables for unused,
overused, and expiring licences, each row linking to the affected users. §3.4 defines single and
bulk assign/remove with confirmation, from the user detail or the licence report. §3.5 requires a
consistent **license missing** state across every gated feature. Resolved §11.1 makes unused
detection advisory only.

Build the optimization route and `OptimizationCards`, the `LicenseAssignDialog` (single + bulk,
plan preview and confirmation, calling T-0645, with per-row results), and a reusable
`LicenseGateState` component rendering the T-0646 gate result as the explanation-with-required-plan
state. Provide no auto-remove affordance. Extend the T-0647 `licensingApi.ts` client. Use report
theme tokens only.

## Acceptance

- [ ] Optimization cards render unused/overused/expiring with working links to affected users,
      and no automatic removal action.
- [ ] The assign/remove dialog shows the plan preview, requires confirmation, and renders
      per-row bulk results.
- [ ] `LicenseGateState` renders the required plan for a gated feature and is reusable by other
      gated surfaces.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

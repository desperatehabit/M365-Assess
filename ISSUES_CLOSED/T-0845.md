# T-0845 — Deploy, edit, and assign Autopilot deployment profiles

## Report

T-0328 persists AutopilotProfileTemplates and lists a tenant's live deployment profiles, but
nothing writes a profile to a tenant. SPEC §3.4 ("create/edit/assign deployment profiles; group
tags") and §6 (`POST`/`PATCH`/`DELETE /v1/tenants/{id}/autopilot/profiles`) need:

- **Deploy a template** to one or more tenants: create the `windowsAutopilotDeploymentProfile`
  from `profileJson`, with a plan preview (create vs. existing name) and per-target results,
  multi-tenant apply behind `confirmTargetCount` (as T-0306/T-0327).
- **Edit and delete** a live profile with preview and typed-name confirmation for delete.
- **Assign** a profile to groups (`/assignments`), with the template's `groupTag` offered as a
  dynamic-group hint.

All writes behind `Endpoint.Autopilot.ReadWrite` or `Remediation.Apply`, audited with
before/after.

## Acceptance

- [x] A template deploys to tenants with a preview and per-target results.
- [x] Live profiles can be edited, deleted (confirmed), and assigned to groups.
- [x] Every write is audited with before/after.
- [x] Tests cover the worker and routes and fail without them.
- [x] No file outside `scope` is modified.

## Resolution

- **Worker** (`Set-AutopilotProfile.ps1`, beta `windowsAutopilotDeploymentProfiles`): `create`
  refuses a display name already in the tenant (409, no duplicates); `update` PATCHes with the
  live `@odata.type`; `delete` needs the exact name and refuses an assigned profile up front
  (Graph will not delete one) with the assignment count; `assign` plans adds (skipping groups
  already assigned) and removes (by assignment id), applies each as a step with its own result,
  and reports `partial` when some fail. Every applied write returns an audit event with
  before/after and the result.
- **Routes** (`autopilot-profiles-write.ts`): create (body or `templateId`), update, delete, and
  assignment changes on `/v1/tenants/{id}/autopilot/profiles`, plus
  `POST /v1/autopilot/profile-templates/:id/deploy` with per-target results and
  `confirmTargetCount` for more than one tenant. Full bodies use the T-0328 template validator;
  PATCH bodies a partial check (no managed fields, no type change, no credentials).
- **Scope extension:** `repository/autopilot-profiles.ts` exports its validator as
  `validateAutopilotProfile` (a rename plus `export`), so live writes and templates share one
  rule set.
- The group tag suggestion stays informational: Autopilot assigns profiles to groups, and a
  dynamic group on the tag is created outside this ticket.

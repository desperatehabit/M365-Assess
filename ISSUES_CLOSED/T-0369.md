# T-0369 — CVE Management page

## Report

EPIC-019 SPEC.md §3.4 fixes the **CVE Management** page: table columns CVE · Scope · Reason ·
Expires · Created by with row actions `Add exception`, `Edit`, `Remove`. Exceptions expire and
re-surface the CVE. It consumes the T-0368 CRUD route.

Deliver the CVE Management page, a `CveExceptionTable`, and a `CveExceptionDialog` for add/edit.
The dialog enforces the mandatory expiry date and the `all`/`device`/`software` scope selection
from §11.3; expired rows are visually flagged. Kit tokens only.

## Acceptance

- [ ] The table renders CVE, scope, reason, expiry, and creator, and flags expired exceptions.
- [ ] Add/edit enforces a mandatory expiry and the scope selector; remove works with confirmation.
- [ ] Expired exceptions are shown as re-surfaced, not suppressed.
- [ ] Component tests cover the table, dialog validation, and expiry flag and fail without them.
- [ ] No file outside `scope` is modified.

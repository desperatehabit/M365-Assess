# T-0626 — Audit exclusion windows and scheduled-search suppression

## Report

EPIC-032 SPEC.md §3.6 defines **Exclusion Windows**: scheduled periods during which audit
searches are skipped (e.g. a vacation), showing active/upcoming windows. §4.4 says creating a
window makes scheduled searches skip it and the window auto-expires. §6 exposes
`POST /v1/tenants/{id}/audit/exclusion-windows`. Resolved §11.4 adopts **portal-only** windows:
they suppress portal scheduled searches only and make no Microsoft-side changes.

Build the window create/list routes over the T-0621 repository and a `scheduler/audit-exclusion.ts`
helper that reports whether a given instant falls inside an active window; the T-0623 scheduled
search run consults this helper before dispatching (prose cross-ref). Windows auto-expire by
`endsAt`. Mutations write an `AuditEvent`. Extend `portal.v1.yaml`.

## Acceptance

- [ ] Active and upcoming windows are created and listed; an expired window no longer suppresses.
- [ ] A scheduled search inside an active window is skipped, and the skip is recorded.
- [ ] The window is portal-only: no Microsoft-side configuration is read or written.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

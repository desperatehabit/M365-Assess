# T-0407 — Transport rules and connectors UI

## Report

EPIC-021 SPEC.md §3.1 and §3.2 fix the UI under *Email & Exchange → Transport*: the **Transport
Rules** table (name, priority, state, conditions, actions, exceptions, last modified) with
`View`, `Edit`, `Enable/Disable`, `Set priority`, `Clone`, `Clone to template`, `Delete`, and the
**Connectors** table (name, type, state, from/to, TLS, last modified) with `View`, `Edit`,
`Enable/Disable`, `Clone to template`, `Delete`. Theme per `02-ui-design.md`.

Deliver the Next.js pages above using the read APIs (T-0401, T-0404) and write routes (T-0402,
T-0404): the rule condition/action builder, the explicit priority control, and the plan-preview/
confirmation dialogs. Disabling a mail-flow connector or changing rule priority surfaces the
warning (T-0402, T-0404) before apply. No browser call reaches a tenant directly.

## Acceptance

- [ ] Transport Rules table renders the §3.1 columns and row actions from the BFF.
- [ ] Connectors table renders the §3.2 columns and row actions from the BFF.
- [ ] Writes open a plan-preview/confirmation dialog; priority and connector-disable warnings show before apply.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

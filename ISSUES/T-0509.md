# T-0509 — LIS location CRUD

## Report

EPIC-026 SPEC.md §2 US-5, §3.4, §4.4, and §6 define **LIS Locations**: manage Location
Information Service locations used for emergency calling with CRUD over address/civic fields and
validation of those fields. §6 exposes `GET`/`POST`/`PATCH`/`DELETE` under
`/v1/tenants/{id}/teams/lis`; §8 routes writes through **EPIC-006** and audits them.

Deliver an `Invoke-LisLocation.ps1` handler (entrypoint `invoke-lis-location.ps1`) for list,
create, update, and delete, applying writes through the EPIC-006 gated executor (T-0108) and
recording a `TeamOperation` (T-0501). The routes validate `teams.voice` + `Remediation.Apply`
and tenant scope, and validate required civic fields before write; the page renders
`LisLocations` with the CRUD forms. Extend `portal.v1.yaml`.

## Acceptance

- [ ] LIS locations list, create, update, and delete round-trip through the API.
- [ ] Missing required civic fields are rejected before any write.
- [ ] Every change is audited; callers without `teams.voice` are refused.
- [ ] A test covers CRUD and address validation and fails without it.
- [ ] No file outside `scope` is modified.

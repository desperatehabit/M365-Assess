# T-0328 — Autopilot devices, add-device import, and profile templates

## Report

EPIC-017 SPEC.md §3.4 and §4.3 define **Autopilot Devices** (list + detail: serial, group tag,
profile, enrollment state), an **Add Device** wizard (manual, CSV import, device-prep import),
and **Autopilot Profiles** (deployment profiles, group tags). Duplicate serials must be detected
and reported. §5 adds `AutopilotProfileTemplate` (`id`, `name`, `profileJson`, `groupTag`) and §6
fixes the `/v1/tenants/{id}/autopilot/*` routes.

Deliver `Import-AutopilotDevices.ps1` + entrypoint (per-row results with duplicate detection),
migration `0042_autopilot_profile_templates.sql`, an `autopilot-profiles.ts` repository, and the
Autopilot routes (devices list/detail, import, profiles CRUD) behind the T-0108 gated-write seam
and the RBAC `intune.autopilot` permission. Each profile write is audited.

## Acceptance

- [ ] The devices route lists Autopilot devices with serial, group tag, profile, and enrollment state.
- [ ] Import accepts manual/CSV/device-prep rows and reports duplicate serials per row.
- [ ] Profile templates persist and CRUD works; each write is audited.
- [ ] Tests cover the route and worker and fail without them.
- [ ] No file outside `scope` is modified.

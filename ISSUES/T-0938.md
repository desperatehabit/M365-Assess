# T-0938 — XLSX pass rates use three different formulas

## Report

The walk's XLSX shows different pass rates for the same profile:

| Sheet | Profile | Shown | Formula |
|---|---|---|---|
| Summary | E3-L1 | 24.2% (8/33) | pass ÷ (pass + fail + warning). The strict rule from #802. |
| Summary | E3 Combined | 14.1% (10/71) | Review included in the denominator |
| Grouped by Profile | E3-L1 | 15.7% (8/51) | Review included in the denominator |

## Cause

`Export-ComplianceMatrix.ps1` computes the rate in three places. The strict rule is around line
243, the combined row around line 356, and the grouped sheet around line 492. Only the first
follows #802.

## Fix direction

Use one shared helper for the strict rule, and use it on every sheet and row.

## Acceptance

- [ ] E3-L1 shows the same pass rate on every sheet.
- [ ] Every pass rate in the XLSX uses the strict formula.
- [ ] No file outside `scope` is modified.

# T-0938 — XLSX pass rates use three different formulas

## Report

The walk's XLSX shows different pass rates for the same profile:

| Sheet | Profile | Shown | Formula |
|---|---|---|---|
| Summary | E3-L1 | 24.2% (8/33) | pass ÷ (pass + fail + warning). The strict rule from #802. |
| Summary | E3 Combined | 14.1% (10/71) | Review included in the denominator |
| Grouped by Profile | E3-L1 | 15.7% (8/51) | Review included in the denominator |

## Cause

`Export-ComplianceMatrix.ps1` computes the rate in three places. The strict rule is around line
243, the combined row around line 356, and the grouped sheet around line 492. Only the first
follows #802.

## Fix direction

Use one shared helper for the strict rule, and use it on every sheet and row.

## Acceptance

- [x] E3-L1 shows the same pass rate on every sheet.
- [x] Every pass rate in the XLSX uses the strict formula.
- [x] No file outside `scope` is modified.

## Fix

Added one private helper, `Get-StrictPassRate` (`Pass / (Pass + Fail + Warning)`,
one decimal, zero when the denominator is zero), to
`Export-ComplianceMatrix.ps1` and replaced every rate calculation with it:

- Summary framework row.
- Summary profile and maturity sub-rows.
- Summary combined `<tier> Combined` row (previously `Pass / Mapped`, which
  included Review).
- Grouped by Profile rows (previously `Passed / Mapped`).
- Grouped by Profile combined `<tier> Combined` row.

Tests run: `tests/Common/Export-ComplianceMatrix.Tests.ps1` — 9 passed. The new
fixture (four CIS E3-L1/E5-L1 checks, one per status, plus one E5-L1-only check)
asserts E3-L1 = 33.3% and E5-L1 = 50.0% on both the Summary and Grouped by
Profile sheets, asserts the combined E3 row matches on both sheets, and checks
every Summary profile row and every Grouped row against the strict formula.
The test is skipped when ImportExcel is unavailable.

# T-0704 — CustomTest and immutable CustomTestVersion schema and repository

## Report

EPIC-036 SPEC.md §5 defines `CustomTest` (`id`, `name`, `category`, `enabled`, `alertsEnabled`,
`currentVersionId`) and `CustomTestVersion` (`id`, `testId`, `content`, `markdownTemplate`,
`parameters`, `createdAt`, `createdBy`) with versions marked **immutable**. §2 US-3/US-4 require
authoring, versioning, and enable/disable.

Deliver migration `0106_custom_tests.sql` creating both tables, plus repository methods to CRUD
custom tests, append an immutable version, list versions, and repoint `currentVersionId`. Updates
to an existing version are rejected by the repository (append-only). Parameter payloads are stored
as JSON and validated by T-0705, not here. Test changes write `AuditEvent`.

## Acceptance

- [ ] Migration `0106` applies after the latest migration, is re-runnable, and advances `SchemaVersion`.
- [ ] Appending a version never mutates an existing version row; the repository refuses in-place edits.
- [ ] `currentVersionId` repoints on save and old versions remain readable.
- [ ] A test covers immutability and fails without it.
- [ ] No file outside `scope` is modified.

# T-0364 — Defender setup deploy worker and API

## Report

EPIC-019 SPEC.md §3.2 and §4.2 define the **Defender Setup** wizard: select policy areas and
target scope, produce a **plan**, then create the policies (AV/EDR/ASR/compliance/exclusion), with
an optional "Save as Intune templates" output. §6 fixes `POST /v1/tenants/{id}/defender/deploy`.
§9 warns of conflicts with existing policies, mitigated by plan preview, an overwrite option, and
audit. §11.2 is resolved to AV/EDR/ASR first.

Deliver `Deploy-DefenderPolicies.ps1` + entrypoint and the BFF deploy route behind the T-0108
gated-write seam. The worker builds a plan per selected policy area (diffing against live
policies), supports an explicit overwrite switch, applies on confirm, and, when the caller
requests it, persists a T-0363 `DefenderDeploymentTemplate` and hands off to the Intune template
path (EPIC-016). Every created policy is audited.

## Acceptance

- [ ] The deploy route returns a plan per policy area and supports an overwrite option for conflicts.
- [ ] Apply creates the selected policies (AV/EDR/ASR first) and audits each write.
- [ ] When save-as-template is requested, a T-0363 template is persisted; otherwise none is written.
- [ ] Tests cover the route and worker and fail without them.
- [ ] No file outside `scope` is modified.

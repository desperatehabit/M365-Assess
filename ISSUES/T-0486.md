# T-0486 — Add-site wizard, delete confirmation, and recycle-bin UI

## Report

EPIC-025 SPEC.md §3.2 and §3.1 require a single-or-bulk add wizard (type, owners, template,
sharing settings), a delete confirmation naming the site, a deleted-sites restore path, and a
recycle-bin surface. §9 requires confirmation naming the site and no silent partial success.

Deliver `AddSiteWizard` (single form plus bulk CSV upload with per-row results from T-0484),
`SiteDeleteDialog` (names the site, requires explicit confirm), and `RecycleBin` (list,
restore, empty with confirm) against the T-0485 API. Wire them into the Sites page (T-0483). A
Vitest/Testing-Library test covers the wizard steps, the bulk result render, the delete confirm
gate, and the recycle-bin list.

## Acceptance

- [ ] The wizard creates a single site and uploads a bulk CSV, showing per-row results.
- [ ] Delete cannot proceed without the explicit confirmation dialog naming the site.
- [ ] Recycle-bin list, restore, and empty render with confirmation on empty.
- [ ] A test covers the wizard, confirm gate, and recycle bin and fails without it.
- [ ] No file outside `scope` is modified.

# T-0487 — Storage composition and age-threshold version cleanup

## Report

EPIC-025 SPEC.md §2 US-4, §3.3, and §4.2 define storage composition (documents/versions/recycle
bin) and a **Version cleanup** action that shows what will be removed before apply and is
irreversible for old versions. §6 exposes `GET .../storage` and `POST .../versions/cleanup`.
§9 requires plan preview, explicit confirmation, and audit. §11 item 2 is resolved (adopted):
version cleanup uses an **age threshold with a manual override** — cleanup removes versions
older than a chosen age (default threshold), and an operator may additionally select or exclude
specific versions.

Deliver a `Get-SiteStorage.ps1` handler (entrypoint `get-site-storage.ps1`) returning stored
bytes split into documents/versions/recycle bin and reclaimable space, and an
`Invoke-VersionCleanup.ps1` handler (entrypoint `invoke-version-cleanup.ps1`) that computes the
cleanup plan from the age threshold plus the manual include/exclude override and applies through
the EPIC-006 gated executor (T-0108). The route validates `sharepoint.cleanup` +
`Remediation.Apply` and requires confirmation; `StoragePanel` renders the composition and the
cleanup preview. Extend `portal.v1.yaml`.

## Acceptance

- [ ] Storage composition renders documents/versions/recycle-bin bytes and reclaimable total.
- [ ] Cleanup previews affected versions before apply; nothing is deleted on preview.
- [ ] The age threshold is applied and a manual include/exclude override is honored.
- [ ] A test covers the plan preview, the age threshold, and the override and fails without it.
- [ ] No file outside `scope` is modified.

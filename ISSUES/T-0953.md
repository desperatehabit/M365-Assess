# T-0953 — COMPLIANCE-COMMS-001 can never run: it calls a cmdlet that does not exist

## Report

- `Get-ComplianceSecurityConfig.ps1` (around lines 328-362) tests
  `Get-Command Get-CommunicationCompliancePolicy` and otherwise reports Review with
  "Cmdlet not available".
- Security & Compliance PowerShell has no `Get-CommunicationCompliancePolicy`. Communication
  compliance policies are read with `Get-SupervisoryReviewPolicyV2`.
- Verified in an app-only IPPS session on the live tenant: `Get-CommunicationCompliancePolicy`
  does not exist; `Get-SupervisoryReviewPolicyV2` exists and returns 0 policies. Every tenant
  therefore gets Review, whatever its configuration.

## Fix direction

- Use `Get-SupervisoryReviewPolicyV2`; Pass with at least one enabled policy, Fail with none.
- Keep the Review fallback for a session where the cmdlet is genuinely unavailable (role or
  license), and say which.

## Acceptance

- [ ] A tenant with no communication compliance policies reports Fail with a count of 0.
- [ ] Tests mock `Get-SupervisoryReviewPolicyV2` and fail without the change.

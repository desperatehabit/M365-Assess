# T-0589 — Purview Compliance UI: labels, SITs, and templates

## Report

EPIC-030 SPEC.md §3.3 and §3.4 define the **Sensitivity Labels** and **Sensitive Info Types**
tables; §3.6 defines the per-area **Templates** pages (DLP, Retention, Label, SIT, Safe Links
Templates) with `View`, `Edit`, `Clone`, `Deploy`, `Export`, `Delete` and variable-driven deploy.
§4.3 requires the UI to show which labels are published and to whom; §11.2 requires the label
editor to surface the second-reviewer requirement for encryption changes.

Deliver the labels and SITs pages (against T-0587), including the publish/publishing-policy view
and the encryption second-reviewer indicator, and the shared templates page (against T-0586) with
the deploy drawer, variable inputs, and partial-failure reporting. Theme per
[`02-ui-design.md`](../../docs/portal-specs/00-guides/02-ui-design.md).

## Acceptance

- [ ] Labels and SITs pages render the §3.3/§3.4 columns and row actions, read-only where required.
- [ ] Published-to scope is visible per label; encryption changes show the second-reviewer state.
- [ ] The templates page supports Deploy with variables and displays per-target partial failures.
- [ ] A test covers template deploy and label rendering and fails without it.
- [ ] No file outside `scope` is modified.

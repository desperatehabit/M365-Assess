# T-0006 — Per-tenant worker entrypoint (run-tenant.ps1)

## Report

EPIC-001 SPEC.md §4.2 fixes the child-process contract:

```
worker: pwsh -File run-tenant.ps1 -ContextFile <run>/context.json -OutputFolder <run>/<tenant>
child:  rehydrate RunContext -> Invoke-M365Assessment -Context $ctx -> artifacts + result.json -> exit
```

- One child `pwsh` per tenant (EXO/Purview mutual exclusion + process-global SDKs —
  `01-architecture.md` §3.1).
- Child exit code + `result.json` **result envelope** (T-0007) are the contract; stdout/stderr
  are diagnostics only.
- The `M365Portal.Workers` module hosts the reusable handler functions (context rehydration,
  artifact enumeration, envelope emission).

## Acceptance

- [ ] `run-tenant.ps1` rehydrates `RunContext` from `-ContextFile`, runs the assessment, writes
      artifacts and a result envelope, and sets an exit code reflecting success/failure.
- [ ] A Pester test drives the entrypoint with a stub context and asserts the result envelope
      and exit code.
- [ ] The worker process loads the module rather than reimplementing domain logic.
- [ ] No file outside `scope` is modified.

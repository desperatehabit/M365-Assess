# T-0326 — App upload wizard and Queued Applications page

## Report

EPIC-017 SPEC.md §3.2 fixes the upload `Wizard`: choose app type → provide source (package upload,
Store link) → detection/requirement rules → assignment → confirm. The **Queued Applications**
page shows queue progress and reuses the EPIC-003/EPIC-007 queue tracking. Per §11.1 the wizard
offers Win32 and Store sources in v1; other source types are shown disabled with a "not yet
supported" note.

Deliver the upload wizard page + `AppUploadWizard` component (multi-step, validating the package
against the signed-URL/size limits from T-0322) and the `QueuedApplications` page reading the
T-0323 queue status route, with re-run on failure. Kit tokens only.

## Acceptance

- [ ] The wizard walks app type → source → rules → assignment → confirm and posts to the upload route.
- [ ] Unsupported source types are visibly disabled, not silently accepted.
- [ ] The Queued Applications page shows per-item progress and offers re-run for failed items.
- [ ] Component tests cover the wizard steps and the queue view and fail without them.
- [ ] No file outside `scope` is modified.

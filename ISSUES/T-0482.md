# T-0482 — SharePoint site list worker and API with filters

## Report

EPIC-025 SPEC.md §2 US-1, §3.1, and §4.3 define the site list: Name/URL · Type (team/
communication) · Owners · Storage used · Last activity · Sensitivity · External sharing, with
filters by type, sharing, storage %, last activity, and sensitivity. §6 exposes `GET
/v1/tenants/{id}/sharepoint/sites`. Sites are read live from Graph/SPO.

Deliver a `Get-SharePointSites.ps1` handler (entrypoint `get-sharepoint-sites.ps1`) that reads
sites through Graph `Sites.ReadWrite.All` (app-only, per §7) and returns a `ResultEnvelope`,
plus the list route that validates `sharepoint.read` and tenant scope and supports cursor
pagination. Filtering is passed to the worker so large tenants are not fully materialized in the
BFF. Extend `portal.v1.yaml`.

## Acceptance

- [ ] `GET /v1/tenants/{id}/sharepoint/sites` returns the §3.1 columns, filtered and paginated.
- [ ] Results are tenant-scoped; a caller without `sharepoint.read` is refused.
- [ ] The BFF performs no Graph call directly (it enqueues the worker).
- [ ] A test covers listing and filtering and fails without the code.
- [ ] No file outside `scope` is modified.

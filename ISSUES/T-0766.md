# T-0766 — Template package manager with versioned JSON bundle format

## Report

EPIC-039 SPEC.md §3.5, §4.3, §6 (US-5): page **Template Package Manager** to import/export
template packages with version and dependency handling, backed by
`GET`/`POST /v1/template-packages`. §11 open question 3 is **resolved (adopted):** the package
format is a **versioned JSON bundle** (a zip container is deferred to a later change).

Define the bundle schema (a `formatVersion`, package name/version, a `contents[]` list of
`{type, name, body}`, and a `dependencies[]` list), validate it on import, and register the
contained items in the local library (T-0761). Export serializes the local library selection to
the same schema. Import is gated by `templates.write` and audited (§8); invalid or conflicting
versions are rejected with structured errors.

## Acceptance

- [ ] The bundle schema carries `formatVersion`, contents, and dependencies, and is documented in code.
- [ ] Import validates the schema, rejects unsupported `formatVersion`, registers items, and audits the import.
- [ ] Export produces a bundle that round-trips through import.
- [ ] The Template Package Manager page supports import and export.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

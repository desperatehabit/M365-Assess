# T-0908 — Resolve macos-latest CI smoke job runner-quota cancellations

## Report

In `.github/workflows/ci.yml` (`cross-platform-smoke` matrix at line ~362), the advisory `macos-latest` smoke job is consistently cancelled before running because of GitHub Actions macOS runner minute quotas on the repository plan.

## Fix direction

Either gate the `macos-latest` matrix entry to manual `workflow_dispatch` / release-branch runs (keeping `ubuntu-latest` on every PR) or replace it with a quota-sustainable cross-platform trigger so PR checks complete without spurious cancellations.

## Acceptance

- [ ] PR CI runs complete cleanly without cancelled `macos-latest` smoke jobs.
- [x] Cross-platform PowerShell smoke coverage remains available via `ubuntu-latest` on PRs and explicit/scheduled `macos-latest` dispatch (if retained).
- [x] No file outside `scope` is modified.

## Fix

`cross-platform-smoke` now computes its matrix from the event: pull requests run
`ubuntu-latest` only, while `workflow_dispatch` and pushes to `main` (release-branch
runs) also run `macos-latest`. The matrix expression uses `fromJSON` so no macOS
runner is requested on PRs, which removes the quota cancellations. The first
acceptance item is verified by the next PR after merge.

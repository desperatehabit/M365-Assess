# T-0934 — SPO-ACCESS-001 reports zero CA policies as "CA policies unavailable"

## Report

The CA collector read the test tenant's policies successfully (0 policies, Security Defaults
on). SPO-ACCESS-001 still reports "CA policies unavailable" as Info.

## Cause

`Get-SharePointSecurityConfig.ps1:893` treats `Count -eq 0` as a read failure. It cannot tell
"no policies" apart from "could not read policies".

## Fix direction

- Tell a failed read (null, or an error recorded by the CA collector) apart from an empty list.
- With zero policies, report that no CA policy covers SharePoint (Fail or Warning, matching how
  the CA-* checks score the same state), not "unavailable".

## Acceptance

- [ ] With zero CA policies read successfully, SPO-ACCESS-001 reports "not covered".
- [ ] With a failed CA read, it still reports "unavailable".
- [ ] No file outside `scope` is modified.

# T-0325 — Applications list and detected-apps UI

## Report

EPIC-017 SPEC.md §3.1 specifies the **Applications** page: table columns Name · Type · Platform ·
Assigned · Install state · Last modified and row actions `View`, `Assign`, `Update`,
`Clone to template`, `Delete`, `View detected`. The detected-apps view is a drawer listing
discovered apps with a **Create app from detected** action that hands off to the upload wizard
(T-0326).

Deliver `applications/page.tsx`, an `ApplicationTable` component with the §3.1 columns and row
actions, and a `DetectedAppsDrawer` component. Data comes from the T-0321 list/detected route;
the theme follows [`02-ui-design.md`](../../docs/portal-specs/00-guides/02-ui-design.md) tokens.
`Assign` deep-links the assignment flow (T-0324) and `Create app from detected` deep-links the
wizard (T-0326).

## Acceptance

- [ ] The page renders the §3.1 columns with live app data and the documented row actions.
- [ ] The detected-apps drawer lists discovered apps and offers "Create app from detected".
- [ ] Row actions are permission-filtered through the RBAC seam.
- [ ] Component tests cover rendering and the detected-drawer hand-off and fail without them.
- [ ] No file outside `scope` is modified.

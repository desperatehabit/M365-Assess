# T-0753 — Roles page with pattern editor and API Clients page

## Report

EPIC-038 SPEC.md §3.2: page **Roles** with base-role rows read-only and custom roles editable;
columns Name, Type (base/custom), Permissions (include/exclude pattern counts), Users; row
actions `View`, `Clone`, `Edit` (custom only), `Delete` (custom only, blocked if in use). The
role editor has two `.chip` pattern lists (**Include**, **Exclude**) with a permission search and
a **Preview effective permissions** panel resolved against the permission registry. SPEC.md §3.3:
page **API Clients** with columns Name, App ID (mono), Role(s), IP ranges, Rate limit, Enabled,
Last used; row actions `View`, `Edit`, `Rotate secret` (shows once), `Enable/Disable`, `Delete`;
`Add client` dialog (name, role(s), IP ranges `Any`/CIDR, rate limit).

Build both pages and their components against the T-0745/T-0747 APIs, reusing the `PermissionGate`
from T-0752 for admin-only actions. `Rotate secret` must show the returned secret exactly once.

## Acceptance

- [ ] Roles page is read-only for base roles and editable for custom roles; delete is blocked when in use.
- [ ] The role editor renders include/exclude `.chip` lists and a working preview panel.
- [ ] API Clients page renders the §3.3 columns and dialog, and `Rotate secret` shows the secret once.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

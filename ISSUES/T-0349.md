# T-0349 — Device detail page, tabs, and action history

## Report

EPIC-018 SPEC.md §3.2 fixes the **Device detail** tabs: Overview · Hardware · Software ·
Policies · Encryption · Actions. The Actions tab shows the append-only action history from T-0343;
the Encryption tab shows BitLocker status from T-0342 (key retrieval is handled by the reveal
component in T-0350).

Deliver the device detail page and `DeviceOverviewTabs` (rendering the T-0342 payload) plus a
`DeviceActionHistory` component reading the T-0343 history route. The page is read-only; actions
are launched from the row/dialog surfaces.

## Acceptance

- [ ] The detail page renders all six §3.2 tabs from the device-detail API.
- [ ] The Actions tab lists action history newest first with actor, reason, and result.
- [ ] BitLocker status renders in the Encryption tab without revealing key material.
- [ ] Component tests cover tab rendering and history listing and fail without them.
- [ ] No file outside `scope` is modified.

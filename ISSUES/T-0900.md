# T-0900 — Groups: Convert has no endpoint, create form GAL/delivery options are decorative, and worker limits

## Report

Left over from T-0883. (1) Convert has no BFF route although `Set-Group.ps1` accepts a convert action; the UI shows a not-available notice. (2) The create form's Hide-from-GAL and delivery-management checkboxes are never sent in the create payload. (3) `Set-Group.ps1` treats an empty description as unchanged, so a description cannot be cleared. (4) `Get-Groups.ps1` selects `requireSenderAuthenticationEnabled` from Graph v1.0, which is likely not a valid group property, so the Delivery mgmt column may always read Default. (5) The delivery dialog cannot show existing send-on-behalf entries because the list does not return them.

## Acceptance

- [ ] The behaviour described in the report is fixed.
- [ ] A test covers it and fails without the fix.
- [ ] No file outside `scope` is modified.

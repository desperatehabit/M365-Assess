# T-0885 — Intune Reusable Settings page is missing

## Report

EPIC-016 SPEC §3.3 / US-4 specify a Reusable Settings surface. No file matches
`portal/web/src/app/**/reusable*`, there is no reusable-settings component, and the Intune nav
(`portal/web/src/components/shell/AppNav.tsx:83-99`) has no entry. The backend is wired: the
reusable-settings route is mounted (`portal/bff/src/app.ts:849-855`) with worker
`sync-reusable-settings.ps1` and `InMemoryReusableSettingTemplateRepository`/SQLite
`SqliteReusableSettingTemplateRepository` repositories.

Note: the `app-protection` policy kind returns 501 by design (`portal/bff/src/domain/intune-policy-types.ts:60-78`,
deferred per SPEC §11.1) even though a page links to it; this ticket need not change that.

- [ ] It calls the mounted reusable-settings endpoints.
- [ ] A component test covers rendering and a sync action.

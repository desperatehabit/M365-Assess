# T-0568 — Alert Configuration and Snoozed Alerts UI

## Report

EPIC-029 SPEC.md §3.1 fixes the **Alert Configuration** page (tabs *Alert Configuration* /
*Snoozed Alerts*) with columns Name · Source · Severity · Scope · Channels · State · Last fired,
row actions `View task details`, `Edit`, `Clone & edit`, `Enable/Disable`, `Delete`, `Test`, and the
primary `Add alert` button. §3.3 puts snoozed items on the Snoozed tab with auto-return. Nav is
*Tenant Administration → Alert Configuration* per [`cipp-ui-inventory.md`](../../docs/portal-specs/99-reference/cipp-ui-inventory.md) §3;
theme per [`02-ui-design.md`](../../docs/portal-specs/00-guides/02-ui-design.md).

Deliver the page against the T-0562 rule API and T-0567 events/snooze API: the config table with
enable/disable/delete/test actions and the snoozed tab showing `snoozeUntil`. `Test` calls the
dry-run endpoint (T-0564) and renders the result without delivering. No new server logic.

## Acceptance

- [ ] The Alert Configuration tab renders the §3.1 columns and row actions.
- [ ] Enable/disable, delete, and clone call the rule API and refresh the row.
- [ ] `Test` shows the dry-run match result and delivers nothing.
- [ ] The Snoozed Alerts tab lists snoozed items with their return time.
- [ ] A test covers rendering and the toggle/test actions and fails without it.
- [ ] No file outside `scope` is modified.

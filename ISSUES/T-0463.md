# T-0463 — Message Trace page with CSV export

## Report

EPIC-024 SPEC.md §3.1 fixes the page title **Message Trace**: a filter form (sender, recipient,
subject, date range, status) over a results table (Timestamp · Sender · Recipient · Subject ·
Status · Event) with row actions `View details` and `Export CSV`, and a clear message when the
EXO trace window limit is hit. Nav follows *Tools → Email Tools* per §3; styling uses report
theme tokens only (`02-ui-design.md`, `05-programming.md` §4).

Deliver the message-trace route rendering `MessageTraceForm` and `MessageTraceTable` against the
T-0462 API, with client-side CSV export of the current result set. `View details` opens the
message viewer (T-0464). A Vitest/Testing-Library test covers the empty, loading, loaded, and
window-limit-error states.

## Acceptance

- [ ] The form filters by all §3.1 fields and renders the §3.1 columns.
- [ ] `Export CSV` downloads the current result set; `View details` links to the viewer.
- [ ] The window-limit error from the API renders as a clear message.
- [ ] Empty, loading, loaded, and error states are tested; only tokens are styled.
- [ ] No file outside `scope` is modified.

# T-0709 — Compliance Test Packs and Custom Tests UI

## Report

EPIC-036 SPEC.md §3.1-§3.3 define the UI. **Compliance Test Packs** (nav *Tenant Administration →
Reports*) lists packs with description and check count, row actions `Run`/`View report`/`Configure`,
and a report showing per-control results and a score reusing the report framework-quilt/scoring
components. **Custom Tests** (nav *Tools → Custom Tests*) is a table of Name · Category · Enabled ·
Alerts · Version · Last run with row actions `Edit`, `View versions`, `Enable/Disable test`,
`Enable/Disable alerts`, `Delete`, `Save to GitHub` (EPIC-039) and an editor holding
`ScriptContent`, `MarkdownTemplate`, `TestParameters`, and the **Explore data structure** helper.

Deliver the routes and components wired to the T-0703/T-0706/T-0707 APIs, using report theme tokens
(`02-ui-design.md`) with no colour literals. The `Save to GitHub` action is EPIC-039's and is
rendered disabled with a hand-off note; the `Explore data structure` helper is a local read-only
inspector.

## Acceptance

- [ ] The packs list renders all packs with check counts and wires Run/View report/Configure.
- [ ] A pack report renders per-control results and the score using the shared scoring output.
- [ ] The custom-tests table exposes the listed actions; the editor validates parameters before save.
- [ ] `Save to GitHub` is present but disabled pending EPIC-039.
- [ ] A test covers the surfaces and fails without it; only theme tokens are used.
- [ ] No file outside `scope` is modified.

# T-0366 — TVM vulnerabilities read API

## Report

EPIC-019 SPEC.md §2 US-3 and §3.3 define the **Vulnerabilities** table (CVE · Severity · CVSS ·
Exposed devices · Affected software · Recommendation) with filters and drill-through to affected
devices. §6 fixes `GET /v1/tenants/{id}/defender/vulnerabilities`. §11.1 is resolved to source TVM
data from the **Graph security API** (preferred), and §9 warns of TVM data volume, mitigated by
pagination/filtering.

Deliver a read-only `Get-TvmVulnerabilities.ps1` + entrypoint that reads the Graph security API
(defender vulnerabilities / exposure) with pagination and server-side filtering, and the BFF route
behind RBAC `defender.read`. The response includes a drill-through reference listing affected
device ids per CVE. No writes.

## Acceptance

- [ ] `GET /v1/tenants/{id}/defender/vulnerabilities` returns CVEs with severity, CVSS, exposed device count, software, and recommendation.
- [ ] The route paginates/filters and, on drill-through, lists affected devices for a CVE.
- [ ] The worker is read-only; the T-0015 guard test still passes.
- [ ] Tests cover the route and worker and fail without them.
- [ ] No file outside `scope` is modified.

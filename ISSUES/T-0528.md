# T-0528 — Remove-links dialog with plan preview and count confirmation

## Report

EPIC-027 SPEC.md §3.4 and §4.2 require the bulk-removal flow in the UI: select links →
**plan preview** → confirm → apply, with a high-blast-radius warning and an explicit
confirmation naming the count. Row and bulk `Remove link(s)` actions on the Sharing Report
(T-0522) feed this dialog.

Deliver `RemoveLinksDialog` and `RemovalPlanPreview` against the T-0527 API: the preview lists
exactly the links that will be removed, the confirm step requires typing/acknowledging the
count, and the result shows per-link outcomes with no silent partial success. A
Vitest/Testing-Library test covers the preview render, the confirmation gate, and the result
list.

## Acceptance

- [ ] The dialog shows a plan preview of exactly the selected links before any apply.
- [ ] Apply cannot proceed without the explicit count confirmation.
- [ ] Per-link results render, including failures, with no silent partial success.
- [ ] A test covers the preview and confirmation gate and fails without it.
- [ ] No file outside `scope` is modified.

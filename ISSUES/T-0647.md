# T-0647 — Licence report and pricing pages

## Report

EPIC-033 SPEC.md §3.1 defines the **Licences** page: a table of SKU, Enabled, Assigned,
Available, Utilization %, and Monthly cost (if pricing is set), with a utilization bar using the
`--bar-glow` token and row actions `View users`, `Assign`, `Unassign`. §3.3 defines the
**License Pricing** page: an editable per-SKU, per-currency table seeded from defaults. Nav is
*Tenant Administration → Reports → Licence*.

Build the two routes and the `LicenseTable` / `PricingTable` components plus a typed
`licensingApi.ts` client for the T-0642 report and T-0644 pricing endpoints. `View users` links
into the report/users view; `Assign`/`Unassign` open the dialogs delivered by T-0648. The pricing
table edits effective prices (global seed with per-tenant override) and is admin-gated. Use
report theme tokens only; no colour literals.

## Acceptance

- [ ] The licence table renders every §3.1 column and the `--bar-glow` utilization bar; an
      unpriced SKU shows "no pricing".
- [ ] The pricing table edits and persists prices and reflects the effective value for the tenant.
- [ ] A test covers the component states and fails without it; only theme tokens are used.
- [ ] No file outside `scope` is modified.

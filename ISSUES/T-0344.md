# T-0344 — Sync and retire device actions

## Report

EPIC-018 SPEC.md §3.3 and §4.1 define **Sync** (non-destructive; light confirmation) and
**Retire** (removes corporate data; confirmation with a summary). §6 fixes
`POST /v1/tenants/{id}/devices/{deviceId}/actions/{action}` for `sync`/`retire`. §8 requires
confirmation, reason capture, and audit, all routed through EPIC-006 semantics.

Deliver `Invoke-DeviceAction.ps1` + entrypoint and the BFF route behind the T-0108 gated-write
seam and RBAC `devices.actions`. Sync requires no reason; retire requires a short reason and a
confirmation summary naming the data removed. Each action records an append-only `DeviceAction`
(T-0343) with actor, reason, and result.

## Acceptance

- [ ] `sync` and `retire` are applied per device, with a confirmation summary shown before apply.
- [ ] Retire captures a reason; sync does not require one.
- [ ] Each action appends a `DeviceAction` row and an audit event.
- [ ] Tests cover the route and worker and fail without them.
- [ ] No file outside `scope` is modified.

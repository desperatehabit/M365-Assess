# T-0762 — Local template library API and page

## Report

EPIC-039 SPEC.md §3.1 (US-1): page **Template Library** with a source picker (**Local**),
checkbox groups by type (Conditional Access, Intune Configuration, Intune Compliance, Intune
Protection, Template Standards, Group, Policy, CA Templates), a **Configured Template
Libraries** table of imported sets, and row actions `View`, `Clone to tenant`, `Export`,
`Delete`. SPEC.md §6 fixes `GET /v1/template-library` (by type).

Build `library-routes.ts` (list + delete, read permission `templates.read`) backed by the
T-0761 repository, plus the `.card`/`DataTable` page and table. Browsing is read-only (§8);
the `Clone to tenant` action links to the T-0765 drawer. `Export` emits a single template file.
Gate destructive `Delete` on `templates.write` through the T-0743 `Test-PortalAccess` path.

## Acceptance

- [ ] `GET /v1/template-library` lists local items filterable by type; delete requires `templates.write`.
- [ ] The page renders the type checkbox groups and the Configured Template Libraries table with the four row actions.
- [ ] Browsing performs no tenant writes.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

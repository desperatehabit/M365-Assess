# T-0924 — Built-in standards, baselines and other templates can be edited in place

## Report

Rule from the operator (2026-11-19, while scoping T-0922): pre-defined templates must be
locked, and changing one means making a copy first, *"that way the original baselines,
standards, etc. remain intact."* This applies to every template family, not only run templates.

## Current state (from code, not yet checked live)

No template route in `portal/bff/src/routes/` has a built-in or locked concept. A search for
`builtIn`, `isSystem` and `locked` across the `*-templates.ts`, `baselines*.ts` and template
adapters finds nothing. `standards-templates.ts` supports cloning (`"<name> (copy)"`, around
line 440), but `PATCH` and `DELETE` treat every template the same. Any template that ships as
pre-defined content can therefore be changed or deleted, and the original is lost.

To confirm live: open a shipped standards template or baseline, edit it and save. The save
should be refused, and today it is expected to succeed.

## Fix direction

- Add a shared `builtIn: boolean` (or `source: "builtin" | "operator"`) field to every template
  family that ships pre-defined content, set when it is seeded.
- **API:** `PATCH` and `DELETE` on a built-in return 403 with one shared error code (for example
  `template.builtin_locked`). Every family gets `POST …/{id}/copy`, which creates an operator copy
  with `builtIn: false`.
- **UI:** built-ins show a lock badge. Edit and delete are replaced by "Make a copy". Opening a
  built-in in an editor is read-only, with a "Make a copy to edit" banner.
- Seeding or upgrades may refresh built-ins, but must never overwrite operator copies.
- T-0922 (run templates) and T-0923 (report templates) should use the same pattern.

## Acceptance

- [ ] Every template family that ships built-in content marks it `builtIn`.
- [ ] Built-ins cannot be edited, renamed or deleted through the UI or the API.
- [ ] "Make a copy" works on every family and produces an editable operator template.
- [ ] A seed or upgrade refreshes built-ins without touching operator copies.
- [ ] No file outside `scope` is modified, unless the scope review adds to it.

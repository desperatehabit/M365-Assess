# T-0070 — Dashboard demo dataset and tutorial markers

## Report

EPIC-004 SPEC.md §3.5 requires a demo dataset and `data-tutorial` markers (CIPP pattern,
`cipp-ui-patterns.md` §6) so onboarding tours can highlight each widget without touching real
data. US-6 covers in-app tours of the dashboard.

Deliver:

- `dashboard-demo.ts`: a typed demo `DashboardPayload`/`FleetPayload` populated with obvious
  placeholder values only — no real tenant names, domains, or UPNs.
- `dashboard-overview.json`: the tour definition naming each widget's `data-tutorial` marker.
- `data-tutorial` attributes on the T-0064 widget chrome, driven by the tour definition.
- A test asserting the demo payload is valid against the T-0061 contract and uses no real data.

## Acceptance

- [ ] A demo mode renders the dashboard from the demo dataset without any API call.
- [ ] Each v1 widget exposes a `data-tutorial` marker named by the tour definition.
- [ ] The demo dataset uses placeholder identifiers only.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

# T-0897 — Workers use an invalid `$Var?` string interpolation in Graph URLs

## Report

`Get-SiteBrowser.ps1` was fixed in T-0855: `"/v1.0/sites/$SiteId?`$select=..."` parses `$SiteId?` as a variable name, so the request goes to the wrong URL. The same pattern exists in `Get-LapsCredentials`, `Invoke-BecCheck`, `Invoke-UserAction`, `Invoke-UserOffboarding`, `Update-UserLicense` and `Set-TenantUserProperties`. Fix each with `${Var}` and add a test per worker that asserts the requested URI.

## Acceptance

- [ ] The behaviour described in the report is fixed.
- [ ] A test covers it and fails without the fix.
- [ ] No file outside `scope` is modified.

# T-0606 — Fleet secure score API

## Report

EPIC-031 SPEC.md §2 US-6 and §3.5 define the **Secure Score — Table Overview**: all-tenants score
table/card grid, sortable, respecting RBAC scope. §6 fixes `GET /v1/secure-score/fleet`. §7 states
the fleet view is filtered by `UserScope` (full RBAC is EPIC-038; this epic uses the EPIC-001/EPIC-038
scope seam in prose).

Deliver the fleet route reading the latest snapshot per tenant from the T-0601 repository and
returning current score/percentage plus a short trend series for sparklines, filtered to the
caller's visible tenants (tenant groups come from EPIC-002, T-0026, prose). No UI here.

## Acceptance

- [ ] `GET /v1/secure-score/fleet` returns the latest score per visible tenant with a trend series.
- [ ] The response is filtered by the caller's tenant scope, not returned unfiltered.
- [ ] A tenant with no snapshot is reported as such rather than omitted silently.
- [ ] A test covers scoping and missing-snapshot handling and fails without the code.
- [ ] No file outside `scope` is modified.

# T-0128 — Custom-script output rendering via markdown template

## Report

EPIC-007 SPEC.md §3.3 gives each custom script a `MarkdownTemplate` area for output rendering and
an **Explore data structure** helper; §5 persists `markdownTemplate` per immutable version.
§11.5 resolves output rendering to **markdown template only for v1** (structured blocks deferred).

Deliver:

- `Format-ScriptOutput.ps1`: binds the script's output object to the version's
  `markdownTemplate` and returns the rendered markdown; unknown/missing fields render an explicit
  placeholder rather than throwing.
- A helper that describes the output object's shape for the "Explore data structure" affordance.
- Pester tests for a populated template, a template referencing a missing field, and the
  structure descriptor.

## Acceptance

- [ ] A script's output renders through its markdown template.
- [ ] A template referencing a missing field renders an explicit placeholder, not an error.
- [ ] The structure helper lists the output object's fields.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

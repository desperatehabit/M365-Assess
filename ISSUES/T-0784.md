# T-0784 — Graph Explorer preset list UI

## Report

EPIC-040 SPEC.md §3.1 (US-2): the **saved presets** list on the Graph Explorer page supports
list, run, and add. Build `GraphPresetList.tsx` against the T-0783 API and mount it in the
Graph Explorer page slot created by T-0782.

The list shows each preset's name and method; **Run** loads it into the T-0782 request editor
and executes; **Add** saves the current request with a name; **Delete** removes the caller's
preset. Presets are per-user (resolved in T-0783), so no sharing UI is added. Errors from the
API render inline.

## Acceptance

- [ ] The preset list renders the caller's presets and runs one into the request editor.
- [ ] Add saves the current request; Delete removes the caller's preset and is hidden for others' presets.
- [ ] Empty state is shown when the caller has no presets.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

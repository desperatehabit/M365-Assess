# T-0341 — Managed device list, search, and filter API

## Report

EPIC-018 SPEC.md §2 US-1 and §3.1 define the **Devices** table (Device name · Owner/UPN ·
Platform · Compliance · Ownership · Last check-in · Enrolled · Serial) with filters for platform,
compliance, ownership, last check-in age, and encrypted. §6 fixes `GET /v1/tenants/{id}/devices`
for list/search/filter.

Deliver a read-only `Get-ManagedDevices.ps1` worker handler + `get-managed-devices.ps1` entrypoint
(rehydrating the EPIC-001 RunContext) and the BFF route behind the RBAC `devices.read` permission
(T-0013). Support cursor pagination and server-side filtering so large fleets do not stream fully
into the browser. No device object is persisted; the handler is read-only and the T-0015 guard
still passes.

## Acceptance

- [ ] `GET /v1/tenants/{id}/devices` lists devices with the §3.1 columns and supports the documented filters.
- [ ] Results are tenant-scoped, cursor-paginated, and permission-checked.
- [ ] The handler performs no writes; the T-0015 guard test still passes.
- [ ] Tests cover the route and worker and fail without them.
- [ ] No file outside `scope` is modified.

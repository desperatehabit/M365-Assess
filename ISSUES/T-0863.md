# T-0863 — Mount and deliver EPIC-033 Licensing routes and workers

## Report

The EPIC-033 factories (`createLicensesRoute`, `createLicenseAssignRoutes`,
`createLicenseOptimizationRoute`, `createLicensePricingRoutes`, `createLicenseGatesRoutes`) exist
under `portal/bff/src/routes/` and are tested, but `portal/bff/src/app.ts` imports none of them and
there is no adapter under `portal/bff/src/adapters/`, so the endpoints 404.

Worker entrypoints the routes name are missing from `portal/workers/`:

- `get-license-optimization.ps1` — named by `portal/bff/src/routes/licenses-optimization.ts:122`;
  `portal/workers/M365Portal.Workers/Get-LicenseOptimization.ps1` exists but the wrapper that
  dotsources it and connects the worker tenant does not (`feature-worker.ts:99` joins
  `workersDir + entrypoint`, so the wrapper is required).
- `get-license-gates.ps1` — `license-gates.ts:27-29` declares the provider interface only; no wrapper
  or implementation exists (only `M365Portal.Workers/Get-LicenseGates.ps1`).

Migration `0056_licensing.sql` and `portal/web/src/app/tenant/reports/{license,optimization,pricing}`
exist.

## Acceptance

- [x] Every EPIC-033 SPEC §6 endpoint returns a non-404 response from a running BFF.
- [x] `get-license-optimization.ps1` and `get-license-gates.ps1` exist and are exercised by a test.
- [x] License assignment/removal, optimization, pricing, and gates run real workers.
- [x] No file outside `scope` is modified.

## Fix

`createLicensingProviders` binds every route seam to its worker: consumption joins the
repository's effective pricing into `get-license-report.ps1`; optimization calls the new
`get-license-optimization.ps1` wrapper with the configurable inactivity window; gates call
the new `get-license-gates.ps1` wrapper and normalize the overlay result; per-user
assign/remove uses the existing `update-user-license.ps1` envelope provider.

`createApp` mounts the five route groups behind `resolveCaller` and the shared authorizer,
over a `SqliteLicensingRepository` (migration 0056): pricing reads/upserts go straight to it,
and each applied/failed assignment row is appended as a `LicenseChange` with its audit
event. Both missing PowerShell entrypoints now dot-source their implementation, connect the
job's tenant, and emit JSON; each has a single-file Pester test. The licensing pricing
permission and the webhook admin scope were made taxonomy-valid (`CIPP.Admin.ReadWrite`)
for the EPIC-038 registry. All endpoints are registered, published through their OpenAPI
fragments, and the checked-in contract is regenerated.

# T-0846 — Application templates, Autopilot, and enrollment pages

## Report

SPEC §3 puts four EPIC-017 surfaces in the nav that have backends but no pages:

- **Application Templates** (§3.3): list, create/edit (config + declared variables with
  defaults), delete, and deploy to tenants with a per-target preview, `values` overrides,
  `confirmTargetCount` for more than one tenant, and per-target results
  (`/v1/app-templates`, T-0327).
- **Autopilot Devices** (§3.4): list with search / group tag / enrollment state filters and a
  detail view (`/v1/tenants/{id}/autopilot/devices`, T-0328), and the **Add Device** wizard —
  manual rows, CSV (Get-WindowsAutoPilotInfo output), or device-prep rows — with the per-row
  preview (ready / duplicate / invalid) before import (`.../autopilot/import`).
- **Autopilot Profiles** (§3.4): live profiles, profile templates CRUD, deploy a template to
  tenants, edit, delete (typed name; refused while assigned), and add/remove group assignments
  (T-0328, T-0845).
- **Enrollment Profiles** (§3.5): Apple ADE and Android Enterprise profiles with create (from a
  body or template), edit, delete, and Apple device assignment, plus token status with the
  `alerts` list surfaced prominently (T-0329).

Add the pages to the Intune nav group (Application templates, Autopilot devices, Autopilot
profiles, Enrollment profiles). Kit tokens only; actions filtered by `Endpoint.Application.*` /
`Endpoint.Autopilot.*` when permissions are resolved.

## Acceptance

- [ ] Each page renders its route's data and walks its writes through preview before apply.
- [ ] Autopilot import shows per-row results, including duplicates, before and after import.
- [ ] Expiring and expired enrollment tokens are visible without opening a profile.
- [ ] The nav links every EPIC-017 page.
- [ ] Component tests cover each page and fail without it.
- [ ] No file outside `scope` is modified.

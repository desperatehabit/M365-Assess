# T-0781 — Graph Explorer request execution API

## Report

EPIC-040 SPEC.md §3.1, §4.1, §6, §7, §8 (US-1): `POST /v1/tenants/{id}/graph-explorer` runs a
request against the selected tenant with the portal's credentials and returns status, headers,
duration, and formatted JSON. §11 open question 1 is **resolved (adopted): read-only by
default; write methods are admin-only and audited.**

Build `graph-explorer-service.ts` (method allowlist, URL validation against the Graph base,
body size limits, no secret exposure) and `graph-explorer-routes.ts`. Enforce that non-`GET`
methods require `CIPP.Admin.*` and that every request — read or write — writes an `AuditEvent`
with actor, tenant, method, URL, and result (read methods audited for privacy). Reject
`$batch`, token endpoints, and any method outside the allowlist. Tenant auth is the portal app
(EPIC-002); requests are limited to what the app is permitted to do.

## Acceptance

- [ ] Read requests execute and return status/headers/duration/body as a typed envelope.
- [ ] Write methods require `CIPP.Admin.*`; a non-admin write is denied and audited.
- [ ] Method allowlist and URL validation reject `$batch` and non-Graph hosts with structured errors.
- [ ] Every request writes an `AuditEvent`; no token or secret value appears in the response or audit.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

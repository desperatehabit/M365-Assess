# T-0544 — Incidents page with filters, severity badge, and bulk actions

## Report

EPIC-028 SPEC.md §3.1 fixes the page title **Incidents**, the table columns, the filters
(severity, status, classification, assigned, date, tenant), the row actions (`View`, `Assign`,
`Set status`, `Classify`, `Comment`, `Resolve`), and the bulk actions (assign, set status with
confirmation). Severity uses the `sev-badge` pattern. Nav follows *Security & Compliance →
Incidents & Alerts* (§3); styling uses report theme tokens only.

Deliver the incidents route rendering `IncidentsTable` against the T-0543 API with the §3.1
filters, the all-tenants toggle, and bulk selection. Row and bulk triage actions open the triage
surfaces (T-0547) rather than duplicating their logic; bulk actions require confirmation. A
Vitest/Testing-Library test covers loading, loaded, empty, filter, and bulk-selection states.

## Acceptance

- [ ] The table renders the §3.1 columns with `sev-badge` severity and all listed filters apply.
- [ ] Bulk assign/set status require confirmation before applying.
- [ ] Row actions route to the triage surfaces and perform no writes here.
- [ ] A test covers the table, filters, and the bulk confirmation gate and fails without it.
- [ ] No file outside `scope` is modified.

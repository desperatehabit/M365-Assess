# T-0941 — Prove the runbook W rows with the operator app

## Report

T-0917 provisions the operator app and the selected write groups. The Phase 2 runbook's
**W** rows (and §5) still need a live pass with that credential. Two rows are expected to
fail for connection reasons, not permissions:

- `Start-HistoricalSearch` needs `New-ComplianceSearch`, which exists only in a Security &
  Compliance session (`Connect-IPPSSession`). Workers open Graph and Exchange Online only.
- `Invoke-TeamsVoice` calls `*-Cs*` cmdlets, but no worker connects `MicrosoftTeams`.

## Fix direction

1. Run each W row against the test tenant after T-0917 opt-in and record pass/fail with the
   operator client id.
2. Add the Security & Compliance connect path to the worker seam if the search row is in
   scope, or split it to its own ticket.
3. Add the MicrosoftTeams connect path for the voice row, or prove the operation is not
   available app-only and document the manual step.
4. Keep the reader app out of every write path.

## Acceptance

- [ ] Every runbook W row passes with the operator app, or has a filed blocker for a
      documented connection gap.
- [ ] The reader credential is never used by a write row.
- [ ] Results are recorded on T-0917 so it can move to `fixed-unverified`.

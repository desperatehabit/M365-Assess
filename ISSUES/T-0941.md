# T-0941 — Prove the runbook W rows with the operator app

## Report

T-0917 provisions the operator app and the selected write groups. The Phase 2 runbook's
**W** rows (and §5) still need a live pass with that credential. Two rows are expected to
fail for connection reasons, not permissions:

- `Start-HistoricalSearch` needs `New-ComplianceSearch`, which exists only in a Security &
  Compliance session (`Connect-IPPSSession`). Workers open Graph and Exchange Online only.
- `Invoke-TeamsVoice` calls `*-Cs*` cmdlets, but no worker connects `MicrosoftTeams`.

## Fix direction

1. Run each W row against the test tenant after T-0917 opt-in and record pass/fail with the
   operator client id.
2. Add the Security & Compliance connect path to the worker seam if the search row is in
   scope, or split it to its own ticket.
3. Add the MicrosoftTeams connect path for the voice row, or prove the operation is not
   available app-only and document the manual step.
4. Keep the reader app out of every write path.

## Progress (2026-11-22)

The two documented connection gaps are fixed in code:

- **Security & Compliance:** `Connect-WorkerTenant` now accepts `Purview` and connects
  it through `Connect-Service` (`Connect-IPPSSession`), always after Graph so the initial
  domain resolves. `start-historical-search.ps1` requests `Purview`, so
  `New-ComplianceSearch` / `Start-ComplianceSearch` run in the right session.
- **MicrosoftTeams:** `Connect-WorkerTenant` now accepts `Teams` and opens an app-only
  `Connect-MicrosoftTeams` session with the same certificate (thumbprint on Windows,
  certificate object elsewhere); it fails early when the module is missing or no
  certificate is available. `invoke-teams-voice.ps1` requests `Graph, Teams`, and
  `Disconnect-WorkerTenant` closes the Teams session.
- Tests: `Connect-WorkerTenant.Tests.ps1` covers Purview ordering, the Teams session and
  its certificate requirement, and Teams disconnect (19 passed); the historical-search
  and voice entrypoint tests cover the service selections (44 passed across both files).

Live-tenant verification remains: run the Phase 2 runbook W rows
(`docs/plans/2026-11-17-phase-2-live-verification.md`) against the test tenant with the
operator app, then record the results here and on T-0917.

## Acceptance

- [ ] Every runbook W row passes with the operator app, or has a filed blocker for a
      documented connection gap. _Both documented gaps are now fixed; the live pass is
      still required._
- [ ] The reader credential is never used by a write row. _T-0940 tests assert the
      operator reference on every write adapter; live confirmation is still required._
- [ ] Results are recorded on T-0917 so it can move to `fixed-unverified`.

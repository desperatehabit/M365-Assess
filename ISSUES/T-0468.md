# T-0468 — Mailbox Restores page and restore wizard

## Report

EPIC-024 SPEC.md §3.4 fixes the page title **Mailbox Restores** and a wizard: select mailbox →
choose scope (mailbox/items/date) → target → confirm; restores are destructive-adjacent and
audited. Nav follows *Tools → Email Tools* per §3; styling uses report theme tokens only.

Deliver the mail-restores route rendering `RestoreWizard` and a list of recent restores with
progress, driving the T-0467 API. The confirm step must present the plan preview and require an
explicit destructive confirmation before starting. A Vitest/Testing-Library test covers each
wizard step, the preview render, and the confirm gate.

## Acceptance

- [ ] The wizard walks mailbox → scope → target → confirm and cannot start without confirm.
- [ ] The plan preview renders what will be restored and where.
- [ ] Recent restores render with live progress from the API.
- [ ] A test covers the wizard and the confirm gate and fails without it.
- [ ] No file outside `scope` is modified.

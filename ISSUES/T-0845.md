# T-0845 — Deploy, edit, and assign Autopilot deployment profiles

## Report

T-0328 persists AutopilotProfileTemplates and lists a tenant's live deployment profiles, but
nothing writes a profile to a tenant. SPEC §3.4 ("create/edit/assign deployment profiles; group
tags") and §6 (`POST`/`PATCH`/`DELETE /v1/tenants/{id}/autopilot/profiles`) need:

- **Deploy a template** to one or more tenants: create the `windowsAutopilotDeploymentProfile`
  from `profileJson`, with a plan preview (create vs. existing name) and per-target results,
  multi-tenant apply behind `confirmTargetCount` (as T-0306/T-0327).
- **Edit and delete** a live profile with preview and typed-name confirmation for delete.
- **Assign** a profile to groups (`/assignments`), with the template's `groupTag` offered as a
  dynamic-group hint.

All writes behind `Endpoint.Autopilot.ReadWrite` or `Remediation.Apply`, audited with
before/after.

## Acceptance

- [ ] A template deploys to tenants with a preview and per-target results.
- [ ] Live profiles can be edited, deleted (confirmed), and assigned to groups.
- [ ] Every write is audited with before/after.
- [ ] Tests cover the worker and routes and fail without them.
- [ ] No file outside `scope` is modified.

# T-0525 — External users report (worker, API, and page)

## Report

EPIC-027 SPEC.md §2 US-3, §3.3, and §6 define the external-users surface: **SharePoint External
Users** with columns External user · Email · Sites · Last access · Invited by and drill-through
to the sites/items they can access. §6 exposes `GET /v1/tenants/{id}/sharing/external-users`;
data is read live from Graph/SPO per §7. §9 calls out enumeration performance and asks for
cache/pagination.

Deliver a `Get-ExternalUsers.ps1` handler (entrypoint `get-external-users.ps1`) that aggregates
external users across sites/OneDrive (using the site list from T-0482) and returns a
`ResultEnvelope`; the read route validating `sharing.read` and tenant scope with cursor
pagination; and the page rendering `ExternalUsersTable` with per-user drill-through to the sites
and items they can access. Extend `portal.v1.yaml`.

## Acceptance

- [ ] `GET /v1/tenants/{id}/sharing/external-users` returns the §3.3 columns, paginated.
- [ ] Drill-through lists the sites/items a selected external user can access.
- [ ] A caller without `sharing.read` is refused; enumeration is paginated.
- [ ] A test covers aggregation and drill-through and fails without it.
- [ ] No file outside `scope` is modified.

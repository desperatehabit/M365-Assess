# T-0443 — Contact create, edit, hide-from-GAL, and delete

## Report

EPIC-023 SPEC.md §2 US-1, §3.1, §4.1, and §8 define contact writes: create/edit/delete with a
plan preview, `Hide from GAL`, and no silent writes — "All writes route through EPIC-006" and
deletes require confirmation. §6 exposes `POST`/`PATCH`/`DELETE` on
`/v1/tenants/{id}/contacts`.

Deliver an `Invoke-ContactAction.ps1` job handler (entrypoint `invoke-contact-action.ps1`) that
executes the EXO cmdlets through the EPIC-006 gated apply path (T-0108) with before/after
capture and an `AuditEvent`, and the CRUD route that validates `contacts.write` plus
`Remediation.Apply` semantics and tenant scope. Deleting requires an explicit confirmation flag
in the request body. Extend `portal.v1.yaml` with the operations and structured errors.

## Acceptance

- [ ] Create, edit, hide-from-GAL, and delete each apply through EPIC-006 with an audit record.
- [ ] Delete without the confirmation flag is refused with a structured error.
- [ ] A caller lacking `contacts.write` is refused; writes are tenant-scoped.
- [ ] A test covers the write path and fails without it.
- [ ] No file outside `scope` is modified.

# T-0448 — Rooms, equipment, and room-list read worker and API

## Report

EPIC-023 SPEC.md §2 US-3, §3.3, and §4.3 cover resource mailboxes: **Rooms**, **Equipment**,
**Room Lists** with Name · Capacity · Location · Type · Hidden, and room lists showing
membership. §6 exposes `GET /v1/tenants/{id}/resources/{kind}`. §5 states resources are read
live from EXO. §11 item 3 is resolved to EXO room lists first (not M365 groups).

Deliver a `Get-Resources.ps1` handler (entrypoint `get-resources.ps1`) that reads room, equipment,
and room-list objects plus room-list membership through the per-tenant EXO process and returns a
`ResultEnvelope`, and the `GET` route that validates `contacts.read`/`resources.read` and tenant
scope. The EXO base is EPIC-020 (prose data dependency). Extend `portal.v1.yaml`.

## Acceptance

- [ ] `GET /v1/tenants/{id}/resources/{kind}` serves rooms, equipment, and room lists.
- [ ] Room-list reads include their membership.
- [ ] Results are tenant-scoped and paginated; an unknown `kind` returns a structured error.
- [ ] A test covers each kind and fails without the code.
- [ ] No file outside `scope` is modified.

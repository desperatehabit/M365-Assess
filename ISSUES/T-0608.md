# T-0608 — Secure score trend chart and peer comparison UI

## Report

EPIC-031 SPEC.md §3.2 defines a trend chart of score over time drawn with a **hand-rolled SVG**
(the module produces self-contained SVG; no charting dependency), fed by the snapshots from T-0604.
§3.3 defines peer comparison as bars against the tenant's score, using *similar* and *all*
organisations and rendering **only when Microsoft provides the data**.

Deliver `SecureScoreTrend.tsx` (SVG line/area over snapshot points, accessible labels) and
`PeerComparison.tsx` (bars vs the tenant score with the benchmark marker), both consumed by the
T-0607 report page. When T-0605 reports peers unavailable, the component renders an explicit
empty state rather than placeholder bars.

## Acceptance

- [ ] The trend component renders an SVG series from the tenant's snapshots.
- [ ] The peer component renders similar/all bars when the T-0605 response provides data.
- [ ] When peers are unavailable, the peer component renders an explicit empty state.
- [ ] A test covers trend rendering and the available/unavailable peer paths and fails without it.
- [ ] No file outside `scope` is modified.

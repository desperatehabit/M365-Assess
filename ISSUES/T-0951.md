# T-0951 — ENTRA-DEVICE-004 always passes because it reads a property Graph does not return

## Report

- `EntraConditionalAccessChecks.ps1` (around lines 130-145) reads
  `azureADJoin.localAdmins.registeredUsers.additionalLocalAdminsCount` from
  `/beta/policies/deviceRegistrationPolicy`. The response has no `registeredUsers` or
  `additionalLocalAdminsCount`, so the value is always 0 and the status is always Pass.
- The response carries the setting CIS 5.1.4.4 is about in
  `azureADJoin.localAdmins.registeringUsers` (`@odata.type` of
  `allDeviceRegistrationMembership`, `enumeratedDeviceRegistrationMembership` or
  `noDeviceRegistrationMembership`).
- Observed on the live tenant: `registeringUsers` is `allDeviceRegistrationMembership`, so every
  user who joins a device becomes its local administrator. The run reported
  `Pass — Additional local admins configured: 0`.

## Fix direction

- Evaluate `localAdmins.registeringUsers`: `noDeviceRegistrationMembership` passes,
  `enumeratedDeviceRegistrationMembership` is Review (list the users/groups count),
  `allDeviceRegistrationMembership` fails.
- Show the setting in `CurrentValue` (`Registering user is local admin: All / Selected / None`).
- Keep ENTRA-DEVICE-003 (`enableGlobalAdmins`) as it is.

## Acceptance

- [ ] `allDeviceRegistrationMembership` produces Fail; `noDeviceRegistrationMembership` produces Pass.
- [ ] Tests use the real response shape and fail without the change.

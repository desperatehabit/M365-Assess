# T-0860 — Mount EPIC-030 Purview routes and add missing compliance-templates endpoint

## Report

The EPIC-030 factories (`createPurviewDlpRoutes`, `createPurviewDlpWriteRoutes`,
`createPurviewLabelRoutes`, `createPurviewRetentionRoutes`, `createSafeLinkRoutes`) exist under
`portal/bff/src/routes/` and are tested, but `portal/bff/src/app.ts` imports none of them and there is
no adapter under `portal/bff/src/adapters/`, so the endpoints 404. Read workers
(`get-purview-dlp.ps1`, `get-purview-labels.ps1`, `get-purview-retention.ps1`, `get-safelinks.ps1`)
exist; DLP writes route through the EPIC-006 remediation apply worker.

Deeper gap (SPEC §3.6, §6, §10): there is **no route module at all** for
`/v1/compliance-templates` CRUD or `/v1/compliance-templates/{id}/deploy`, even though the
repository (`portal/bff/src/repository/purview-compliance.ts`), migration
`portal/db/migrations/0038_purview_compliance.sql`, and consuming UI
(`app/compliance/dlp/page.tsx:178`, `app/compliance/templates/page.tsx:87`) all exist.

## Fix direction

Author `portal/bff/src/routes/compliance-templates.ts`, add the Purview adapter, and mount all six
route groups in `app.ts`.

## Acceptance

- [ ] Every EPIC-030 SPEC §6 endpoint returns a non-404 response from a running BFF.
- [ ] A compliance-templates route module exists and serves the CRUD + deploy endpoints the UI calls.
- [ ] DLP, labels/SITs, retention, and Safe Links run their real workers.
- [ ] No file outside `scope` is modified.

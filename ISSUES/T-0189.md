# T-0189 — Migrate from standards

## Report

EPIC-010 SPEC.md §3.2 exposes a `Migrate from standards` action and §4.4 (US-7) converts an
EPIC-008 standards template into a **staged baseline**. §6 fixes
`POST /v1/baselines/{id}/migrate-from-standards`. §10 requires the result be a valid staged
baseline satisfying the T-0182 save gate.

Deliver the migration handler: it reads an EPIC-008 template (T-0143), maps its standards into at
least one baseline stage, and returns the created baseline. The mapping must satisfy the same
name/assignment/staged-standard validation as a manual save and must not mutate the source
template.

## Acceptance

- [ ] Migration produces a baseline with ≥1 stage whose standards came from the source template.
- [ ] The source template is unchanged; the result passes the T-0182 save validation.
- [ ] Migrating a drift-kind template is rejected with a structured error.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

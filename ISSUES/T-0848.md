# T-0848 — Verify EPIC-018 Graph calls against a live tenant

## Report

The EPIC-018 workers were built against mocked Graph only. Assumptions to confirm or correct:

- **Device list** (`Get-ManagedDevices`): v1.0 `deviceManagement/managedDevices` with
  `$select=id,deviceName,userPrincipalName,operatingSystem,osVersion,complianceState,managementState,deviceType,managedDeviceOwnerType,lastSyncDateTime,enrolledDateTime,serialNumber,isEncrypted`
  and `$top=999`. Confirm the `$select` fields all exist on the v1.0 entity and that
  `$top=999` is sufficient or pagination is needed.
- **Device detail** (`Get-ManagedDevice`): v1.0 `managedDevices/{id}` with the extended
  `$select` (adds `model,manufacturer,storageSpace,totalStorageSpace,phoneNumber,imei`);
  `detectedApps` with `$select=id,displayName,version,publisher`;
  `deviceCompliancePolicyStates` and `deviceConfigurationStates` with
  `$select=id,displayName,state,lastReportedDateTime`. Confirm all four endpoints return
  the expected shapes.
- **Sync / retire** (`Invoke-DeviceAction`): v1.0 `managedDevices/{id}/syncDevice` and
  `managedDevices/{id}/retire` POST endpoints. Confirm the action names and that no
  additional body is required.
- **Wipe / fresh-start** (`Invoke-DeviceWipe`): v1.0 `managedDevices/{id}/wipe` and
  `managedDevices/{id}/freshStart` POST endpoints. Confirm the action names, that
  `wipe` supports `keepEnrollmentData` and `keepUserData` body parameters, and that
  `freshStart` is the correct action name (not `freshStartDevice`).
- **BitLocker keys** (`Get-BitLockerKeys`): v1.0
  `informationProtection/bitlocker/recoveryKeys` with `$filter` on `deviceId`; detail
  endpoint `recoveryKeys/{id}` with `$select=key,createdDateTime`. Confirm the filter
  syntax and that the `key` field is returned (not just a reference).
- **LAPS** (`Get-LapsCredentials`): v1.0
  `directory/deviceLocalCredentials/{id}?$select=id,credentials` for Windows LAPS;
  v1.0 `devices/{id}/getLocalAdminPassword` for legacy LAPS. Confirm the Windows LAPS
  endpoint returns `credentials` as a collection with `userName` and `password` fields,
  and that the legacy endpoint returns the password in the expected shape.

Run each worker against a test tenant, correct any wrong endpoint, verb, or payload, and update
the mocked tests to the observed response shapes. A person must run this; the agent has no
tenant credentials.

## Acceptance

- [ ] Each listed assumption is confirmed or corrected against a live tenant, with the result recorded in this ticket.
- [ ] A BitLocker key is retrieved end to end; a LAPS credential is retrieved on a device that has one.
- [ ] Worker tests reflect observed response shapes; they fail without any corrections made.
- [ ] No file outside `scope` is modified.

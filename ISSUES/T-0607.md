# T-0607 — Tenant Secure Score report UI with Fix linkage

## Report

EPIC-031 SPEC.md §3.1 defines the **Secure Score — <tenant>** page: hero score card (current, max,
percentage) using the report's gradient-clipped `.score-num` and `.score-bar` with a peer benchmark
marker, the achieved/not-achieved split and category breakdown, and an improvement-actions table
(Action · Category · Points · Impact · **Mapped standard** · State). §3.4 and §4.3 define the
**Fix** action: resolve the mapped checkId and open the EPIC-006 remediation plan (T-0105) or the
EPIC-008 standard (T-0141); if none, show "no automated remediation" with a portal link. §2 US-3
uses the peer benchmark marker from T-0605.

Deliver the tenant report page against T-0602 and T-0603 (and T-0605 for the marker): the hero
card, split, category breakdown, and the actions table whose `Fix` link routes to the mapped plan
or standard, or shows the honest unmapped state. Theme per
[`02-ui-design.md`](../../docs/portal-specs/00-guides/02-ui-design.md). No new server logic.

## Acceptance

- [ ] The page renders the hero score, max/percentage, split, and category breakdown.
- [ ] The improvement-actions table shows mapped standard + state per action.
- [ ] `Fix` opens the EPIC-006 plan or EPIC-008 standard for mapped actions.
- [ ] Unmapped actions show "no automated remediation" with a portal link.
- [ ] A test covers rendering and the Fix/mapped/unmapped paths and fails without it.
- [ ] No file outside `scope` is modified.

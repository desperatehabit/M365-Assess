# T-0901 — Mailbox rule edit form shows an empty forwarding field for rules with several recipients

## Report

`portal/web/src/app/email/mailboxes/rules/page.tsx` types `forwardTo` as `unknown` and only pre-fills it when it is a string, so a rule with multiple forward targets (now returned as an array) shows an empty field in the edit form. Pre-fill from arrays (joined) and send back a list; add a test.

## Acceptance

- [ ] The behaviour described in the report is fixed.
- [ ] A test covers it and fails without the fix.
- [ ] No file outside `scope` is modified.

## Resolution notes

- `formatForwardTo` pre-fills the edit field from a string or an array (joined with `; `).
- `parseForwardTo` splits the form value into the address list the BFF/worker expects, so an
  edit preserves every forward target instead of dropping all but a single string.
- The rules test edits a rule with two forward targets, asserts the joined field value, and
  asserts the PATCH body sends the list.

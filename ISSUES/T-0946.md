# T-0946 — Run artifacts list is empty because the assessment writes into a subfolder

## Report

- The run detail page shows `Artifacts (0)` for run `b4d11871-d1c2-4857-8b91-b7c79282af21`,
  which has `artifactPath = runs/<tenantId>/<runId>` and a full output set on disk.
- The assessment writes its files into a timestamped subfolder,
  `<artifactPath>/Assessment_<yyyyMMdd_HHmmss>_<tenant>/` (CSVs, `_Assessment*.json`,
  `_Assessment-Summary*.csv`, the HTML report and the XLSX matrix).
- `indexRunArtifacts` (`portal/bff/src/artifacts/index.ts`, around lines 130-150) calls `readdir`
  on `artifactPath` only and skips every entry that is not a file, so the subfolder and
  everything in it is dropped.
- The download route (`runs-artifacts.ts`, `resolveArtifactFilePath(artifactRoot, artifactPath,
  fileName)`) resolves a bare file name under `artifactPath`, so a nested file cannot be
  downloaded either.

## Fix direction

- Index recursively (bounded depth), returning each file's path relative to `artifactPath`.
- Accept a relative path in the download route; keep the traversal guard so the resolved path
  stays under `artifactPath`.
- Show the relative path (or group by folder) in the Artifacts tab, with the HTML report and
  XLSX matrix first.

## Acceptance

- [ ] Run `b4d11871` lists its CSV, JSON, HTML and XLSX outputs (indexer verified against the real folder: 69 files; needs the portal restarted to show in the GUI).
- [x] A nested artifact downloads; `../` and absolute paths are still rejected.
- [x] Tests cover a nested output folder and the traversal guard, and fail without the change.

## Found while fixing

- Both artifact routes, and the run events (progress stream) route, wrote audit rows with
  `source: "bff"`. `audit_events.source` is CHECK-constrained to `request`, `schedule` and
  `remediation`, so the insert failed and every artifact request returned 500 against the real
  database; the route tests used a fake store and never saw it. The routes now write
  `source: "request"`, the audit input types are narrowed to the allowed values, and an app-level
  test runs the artifact routes against a migrated SQLite database. The progress-stream failure
  may contribute to T-0943.
- The report's theme effect wrote to `localStorage` without a guard. In the sandboxed inline view
  (and in any browser with site data blocked) that throws and unmounts the whole report; the writes
  are now wrapped in `try`.

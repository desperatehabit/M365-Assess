# T-0857 — Mount and wire EPIC-027 Sharing & Permissions routes

## Report

The EPIC-027 factories (`createSharingReportRoute`, `createSharingPermissionsRoute`,
`createExternalUsersRoutes`, `createSharingLinksRemoveRoutes`) exist under `portal/bff/src/routes/`
and are tested, but `portal/bff/src/app.ts` imports none of them and there is no adapter under
`portal/bff/src/adapters/`, so the endpoints 404. Workers (`get-sharing-report.ps1`,
`get-permissions-report.ps1`, `get-external-users.ps1`, `remove-sharing-links.ps1`) and migration
`0035_sharing_link_removal.sql` exist, and the UI (`SharingTable`, `PermissionsTable`,
`ExternalUsersTable`, `RemoveLinksDialog`, `RemovalPlanPreview`, `RiskyLinksView`) is present.

`portal/bff/src/routes/sharing-links-remove.ts:321` hard-fails with 501
(`SHARING_LINKS_UNAVAILABLE`, "not wired for this tenant") whenever the removal provider is absent,
so bulk removal cannot be exercised until the adapter is wired.

## Acceptance

- [ ] Every EPIC-027 SPEC §6 endpoint returns a non-404 response from a running BFF.
- [ ] Sharing report, permissions, external users, and link removal run their real workers.
- [ ] Bulk link removal no longer returns 501 once the provider is configured.
- [ ] No file outside `scope` is modified.

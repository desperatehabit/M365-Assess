# T-0051 — QueueTracker component and live progress client

## Report

EPIC-003 SPEC.md §3.4 defines the `QueueTracker`: a persistent top-bar badge showing active
runs that opens a drawer with per-tenant/per-section progress and a **Cancel** action, plus a
multi-queue variant merging concurrent runs (a tooltip like "17/40 tasks across 3 caches").
§4.2 says the tracker renders section rows with optional expandable check-level detail. EPIC-001
T-0014 provided the progress-event contract; this ticket consumes it. The tracker itself was
reserved for this epic (EPIC-001 SPEC.md §3).

Deliver the `QueueTracker` component and a `useRunEvents.ts` hook that subscribes to the T-0044
SSE stream, dedupes by monotonic sequence, and reconnects on drop. Use report theme tokens
(`02-ui-design.md` §5) only.

## Acceptance

- [ ] The badge shows active runs; the drawer shows per-tenant/per-section progress and Cancel.
- [ ] The hook consumes the versioned event stream, dedupes by sequence, and reconnects.
- [ ] The multi-queue variant merges concurrent runs with an aggregate tooltip.
- [ ] A test covers live updates and fails without the code.
- [ ] No file outside `scope` is modified.

# T-0148 — Alignment report and per-tenant standards report

## Report

EPIC-008 SPEC.md §3.3 defines **Standard & Drift Alignment** with a three-way view switcher:
*Tenant/template summary*, *Tenant rows for each standard*, *Aggregate tenant compliance by
standard*, sharing status vocabulary with EPIC-009 (`compliant`, `non-compliant`,
`accepted deviation`, `customer specific`, `license missing`, `reporting disabled`). §3.4 defines
**Standards Report — <tenant>** with search, a **Standard Logs** drawer, a `Run standard report`
dialog, and a *Compare tenant to standard* mode. §6 adds `GET /v1/standards/alignment` and
`GET /v1/standards/compare/{tenantId}` (US-5).

Deliver the alignment/compare endpoints reading `StandardCompare` rows (written by T-0145) and the
alignment + per-tenant report UI. Colour/priority maps use theme tokens only.

## Acceptance

- [ ] The three alignment views render from the API, including `license missing` and `reporting disabled` states.
- [ ] `GET /v1/standards/compare/{tenantId}` returns current vs expected per check.
- [ ] The per-tenant report renders search and the Standard Logs drawer; a test covers the API.
- [ ] No file outside `scope` is modified.

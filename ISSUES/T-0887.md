# T-0887 — Add navigation sections for post-EPIC-018 feature areas

## Report

`portal/web/src/components/shell/AppNav.tsx:21-107` defines the application navigation. It only has
sections for the EPIC-001..018 areas, so most pages delivered by later epics are unreachable except
by direct URL. Missing nav coverage includes, at least:

- Devices: Defender setup/reports (EPIC-019), Intune reusable settings (EPIC-016).
- Email: mailbox reports and deleted mailboxes (EPIC-020), transport/connectors (EPIC-021),
  spam/quarantine/allow-block (EPIC-022), contacts/resources (EPIC-023), email tools (EPIC-024).
- Collaboration: SharePoint and Teams sections (EPIC-025, EPIC-026, EPIC-027).
- Security & Compliance: Purview compliance/DLP/labels/retention and Safe Links (EPIC-030),
  Secure Score (EPIC-031), audit logs/webhooks (EPIC-032), incidents (EPIC-028).
- Tenant administration: alert configuration/notifications (EPIC-029), licensing (EPIC-033),
  domains/DNS (EPIC-034), backup (EPIC-035).
- Platform admin: settings/branding/features/logbook/preferences (EPIC-037), portal users/API
  clients/API docs (EPIC-038), template library/catalog (EPIC-039), tools/Graph Explorer (EPIC-040),
  compliance test packs/custom tests (EPIC-036).

Some individual page links already exist but point at pages owned by the per-epic tickets; this
ticket adds only the nav structure (sections, grouping, and route links) and must not create or edit
the pages themselves.

## Acceptance

- [ ] `AppNav.tsx` links every page listed above under an appropriate section.
- [ ] A nav test asserts the new section/route groups.
- [ ] No file outside `scope` is modified.

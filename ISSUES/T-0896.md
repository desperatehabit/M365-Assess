# T-0896 — SharePoint Templates page and in-portal site property editing have no backing endpoints

## Report

The SPEC lists a SharePoint Templates nav item and `SharePointTemplate` entity, but §6 defines no templates endpoint, so `AddSiteWizard` has no template options. The site edit page can only show the URL, an admin-center link and Delete because no BFF endpoint edits site properties. Decide scope with the owner, add the endpoints and worker support, then build the Templates page and real edit form. The Permissions and External-users pages currently hand off to `/sharing/*`, whose routes are not mounted (see T-0857).

- [ ] The behaviour described in the report is fixed.

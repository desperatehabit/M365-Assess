# T-0145 — Standard execution worker (report, alert, remediate)

## Report

EPIC-008 SPEC.md §4.2 defines the per-standard three-branch execution shape: (1) read current
state (Graph/EXO/Purview); (2) `remediate` routes through **EPIC-006** (plan/apply, audit) — never
a private write path; (3) `alert` raises through EPIC-029; (4) `report` records current vs
expected (a `Set-CIPPStandardsCompareField` analogue) for alignment. `autoRemediate` implies
`remediate` + `report`. §8 states standards reuse EPIC-006 entirely, and all licence/service/
RBAC/scope/read-only/allowlist gates still apply.

Deliver `Invoke-Standard.ps1` as a worker entrypoint plus its module wiring. It reads current
state, applies the action flags from the effective template (T-0142), honours the licence
classification (T-0144), and writes `StandardCompare` rows. Writes are delegated to the EPIC-006
remediation contract (prose cross-ref); alert delivery is delegated to EPIC-029 (prose).

## Acceptance

- [ ] A `report`-only standard records `current` vs `expected` without writing to the tenant.
- [ ] A standard with `remediate` (or `autoRemediate`) invokes the EPIC-006 plan/apply contract and never writes directly.
- [ ] A standard whose licence is missing is skipped with `license missing` state.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

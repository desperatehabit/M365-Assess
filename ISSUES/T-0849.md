# T-0849 — Mount and deliver EPIC-019 Defender routes with real storage

## Report

`portal/bff/src/routes/defender-{status,deploy,vulnerabilities,mde-onboarding,cve-exceptions,templates}.ts`
define the SPEC §6 endpoints but no factory (`createDefenderStatusRoutes`, `createDefenderDeployRoute`,
`createDefenderVulnerabilitiesRoutes`, `createMdeOnboardingRoutes`, `createDefenderCveExceptionRoutes`,
`createDefenderTemplateRoutes`) is imported in `portal/bff/src/app.ts`; a repo-wide search finds each
only in its own file. `portal/bff/src/adapters/` has no Defender provider, so the endpoints 404 at
runtime. Workers that must back the providers exist (`portal/workers/get-defender-status.ps1`,
`deploy-defender-policies.ps1`, `get-tvm-vulnerabilities.ps1`, `get-mde-onboarding.ps1`).

`portal/bff/src/repository/defender-deployment-templates.ts` also exposes
`createInMemoryDefenderDeploymentTemplateRepository` (`:179`) instead of a SQLite implementation;
migration `portal/db/migrations/0022_defender_deployment_templates.sql` already owns the relational
shape.

UI: `portal/web/src/components/defender/DefenderSetupWizard.tsx` exists but is imported by no page;
there is no `app/security/defender/setup` route (SPEC §3.2). The CVE Report and Device Compliance
report surfaces under Reports (SPEC §3) are absent.

## Fix direction

Add a Defender adapter next to the other worker-backed adapters (`runFeatureWorker` + the tenant
credential block), implement a SQLite `DefenderDeploymentTemplateRepository`, mount all six route
groups in `app.ts` with `ctx.caller`, the shared authorizer, and the audit sink, then render the
setup wizard and the two report surfaces on the existing pages.

## Acceptance

- [ ] Every EPIC-019 SPEC §6 endpoint returns a non-404 response from a running BFF.
- [ ] The callback-URL deploy, CVE exceptions, vulnerability, and MDE onboarding routes run their real workers.
- [ ] Defender deployment templates persist through SQLite, not the in-memory repository.
- [ ] The Defender setup wizard and CVE/Device-Compliance report surfaces render live data.
- [ ] A test covers each mounted route and fails without the mount.
- [ ] No file outside `scope` is modified.

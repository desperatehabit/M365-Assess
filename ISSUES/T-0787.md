# T-0787 — GeoIP database lookup and individual domain check

## Report

EPIC-040 SPEC.md §3.5, §4.3, §6 (US-6): pages **IP Database / Domain Check**. `GET
/v1/geoip/{ip}` returns GeoIP details for an IP; the domain check runs an individual DNS check
for a domain. The domain check **overlaps EPIC-034** (§3.5, §9) — reuse EPIC-034's domain-check
service once available rather than duplicating resolver logic; until then, return a structured
"not yet available" error rather than a second implementation.

Build `geoip-service.ts` backed by a local/offline IP database (no external paid API in v1),
plus the two pages. `tools.read` is required. Results are cached in memory; the service has no
tenant write path.

## Acceptance

- [ ] `GET /v1/geoip/{ip}` returns GeoIP fields for a valid IP and a structured error for an invalid one.
- [ ] The IP Database page renders a lookup form and results.
- [ ] The Domain Check page calls the shared EPIC-034 domain-check service or reports it as not yet available.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

# T-0853 — Mount EPIC-023 Contacts & Resources routes

## Report

All EPIC-023 factories (`createContactsRoutes`, `createContactsCrudRoutes`,
`createContactsImportRoutes`, `createContactTemplateRoutes`, `createContactTemplateDeployRoute`,
`createResourcesRoutes`, `createResourcesCrudRoutes`) exist under `portal/bff/src/routes/` and are
tested, but `portal/bff/src/app.ts` imports none of them and there is no adapter under
`portal/bff/src/adapters/`, so the endpoints 404. Workers (`get-contacts.ps1`, `import-contacts.ps1`,
`invoke-contact-action.ps1`, `invoke-contact-template.ps1`, `deploy-contact-template.ps1`,
`get-resources.ps1`, `invoke-resource-action.ps1`) and migration `0031_contact_templates.sql` exist,
and the UI pages (`email/contacts`, `email/contact-templates`, `email/resources`) are present.

## Acceptance

- [ ] Every EPIC-023 SPEC §6 endpoint returns a non-404 response from a running BFF.
- [ ] Contact import, template deploy, and resource actions run through their real workers.
- [ ] A test covers each mounted route and fails without the mount.
- [ ] No file outside `scope` is modified.

# T-0856 — Mount and deliver EPIC-026 Teams & Voice routes and UI

## Report

The EPIC-026 factories (`createTeamsListRoute`, `createTeamsCreateRoute`,
`createTeamsLifecycleRoutes`, `createTeamsActivityRoutes`, `createLisLocationsRoutes`,
`createTeamsVoiceRoutes`) exist under `portal/bff/src/routes/` and are tested, but
`portal/bff/src/app.ts` imports none of them and there is no adapter under `portal/bff/src/adapters/`,
so the endpoints 404. Workers (`get-teams.ps1`, `new-team.ps1`, `invoke-team-action.ps1`,
`get-teams-activity.ps1`, `invoke-lis-location.ps1`, `invoke-teams-voice.ps1`) exist.

UI gaps (SPEC §3.1, §4.1, §10):

- `components/teams/{AddTeamWizard,TeamDeleteDialog}.tsx` are referenced only by
  `TeamLifecycle.test.tsx` and appear on no page.
- `app/teams/page.tsx:139,147,150,153,156,159,162` links to `/teams/new`, `/teams/{id}`,
  `/teams/{id}/members`, and `/teams/{id}/edit`, none of which exist.

## Acceptance

- [ ] Every EPIC-026 SPEC §6 endpoint returns a non-404 response from a running BFF.
- [ ] Team create, lifecycle, activity, LIS, and voice actions run their real workers.
- [ ] The linked team new/detail/members/edit routes exist and render live data.
- [ ] No file outside `scope` is modified.

# T-0808 — Integrations page (config, test, sync status)

## Report

**PARKED / optional.** EPIC-041 is deferred behind EPIC-038.

EPIC-041 SPEC.md §3.1 (`CIPP → Integrations`): page **Integrations** with one card per
registered connector showing config, a **Test** action, and sync status, plus mapping
configuration for entity sync. Build the page and `IntegrationCard` against the T-0801 registry
and `GET`/`PUT /v1/integrations/{kind}`, `POST …/test`, `POST …/sync` APIs.

Cards are driven by the registry, so a newly registered adapter appears without a page change.
Actions are admin-gated (T-0743 style) and disable while a test/sync is in flight; results
render inline. No connector is enabled by default.

## Acceptance

- [ ] The page lists a card per registered `kind` with config, test, and sync status.
- [ ] Test and sync call the registry APIs and render results inline.
- [ ] Actions are admin-gated; no connector is enabled by default.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

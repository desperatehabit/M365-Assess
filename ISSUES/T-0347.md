# T-0347 — LAPS / local-admin credential retrieval (Windows LAPS and legacy)

## Report

EPIC-018 SPEC.md §2 US-5 and §3.4 define **LAPS/recovery**: retrieve local-admin credentials with
display time-limited and audited. §11.4 is resolved to **support both Windows LAPS and legacy
LAPS**. §6 fixes `GET /v1/tenants/{id}/devices/{deviceId}/laps`.

Deliver `Get-LapsCredentials.ps1` + entrypoint and the route behind the high-privilege RBAC
`devices.keys` permission. The worker probes both backends (Windows LAPS and legacy LAPS) and
returns whichever has a credential for the device, with the backend identified. Each retrieval
appends a `KeyAccessAudit` row via the T-0346 repository. Credentials are returned only in the
response and are never persisted or logged.

## Acceptance

- [ ] `GET .../laps` returns local-admin credentials for a device, identifying Windows LAPS or legacy LAPS.
- [ ] Both backends are supported; a device with neither returns a structured not-found error.
- [ ] Every retrieval is audited and no credential is persisted or logged.
- [ ] Tests cover the route and worker and fail without them.
- [ ] No file outside `scope` is modified.

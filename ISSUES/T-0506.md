# T-0506 — Add-team wizard and lifecycle dialogs

## Report

EPIC-026 SPEC.md §3.1 and §4.1 require an `Add team` create wizard (name, owners, members,
template, visibility) and lifecycle row actions, with delete confirmation naming the team and
archive-before-delete guidance per §8/§9.

Deliver `AddTeamWizard` (fields above, template picker bound to the local `TeamTemplate` list
from T-0501/T-0504) and `TeamDeleteDialog` (names the team, requires explicit confirm), plus
edit/archive/clone affordances, against the T-0504/T-0505 APIs. Wire them into the Teams page
(T-0503). A Vitest/Testing-Library test covers the wizard fields, template selection, and the
delete confirmation gate.

## Acceptance

- [ ] The wizard submits name/owners/members/template/visibility and surfaces per-field errors.
- [ ] Delete cannot proceed without the explicit confirmation dialog naming the team.
- [ ] Archive, clone, and edit actions call the T-0505 API and refresh the table.
- [ ] A test covers the wizard and the delete confirm gate and fails without it.
- [ ] No file outside `scope` is modified.

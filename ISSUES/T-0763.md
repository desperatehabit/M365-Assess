# T-0763 — Community template repos API and Catalog page

## Report

EPIC-039 SPEC.md §3.2 (US-2): page **Catalog** with type chips (Intune Policy, Conditional
Access, Standards, Baseline, Report Builder, Group, PIM Role Settings, Custom Test), repo
cards showing **Built-in** / **Write Access** chips and a `+N more` count, and an `Add repo`
dialog (URL or owner/repo, template types, user/org). SPEC.md §6 fixes
`GET`/`POST`/`DELETE /v1/template-repos` and `GET /v1/template-repos/{id}/templates`.

Build `repo-routes.ts` and `repo-service.ts` on the T-0761 `TemplateRepo` store, including
fetching and indexing a repo's templates. `Add repo` requires `templates.write`; adding or
removing a repo writes an `AuditEvent`. CSP-style untrusted content is never rendered as HTML.
Clone of a community item is out of scope here and handled by T-0765.

## Acceptance

- [ ] `POST`/`DELETE /v1/template-repos` add and remove repos and audit the change; `GET …/{id}/templates` returns the repo's indexed templates.
- [ ] The Catalog page renders type chips, repo cards with Built-in/Write Access chips, and the `+N more` count.
- [ ] `Add repo` accepts URL or owner/repo plus template types.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

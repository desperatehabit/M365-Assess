# T-0935 — Licence gating doesn't reach finding status, so unlicensed checks report Fail

## Report

The test tenant has Office 365 E5 and Business Premium, and neither includes Entra ID P2. In the
walk's run:
- **CA-USERRISK-001**, **CA-SIGNINRISK-001** and **ENTRA-PIM-001** are **Fail**. Their
  `licensing-overlay.json` entries (lines 5-8) require `AAD_PREMIUM_P2`.
- ENTRA-PIM-001's own evidence says "PIM not licensed".
- ENTRA-PRIVREMOTE-001 reports the same licence fact as Review, so the report contradicts
  itself.

## Cause

Licence gating is applied only to the progress display (`Common/Show-CheckProgress.ps1:108-129`).
It does not change the recorded status.

## Fix direction

- After collection, or in `Add-Setting`, compare each check's licensing-overlay requirement with
  the tenant's service plans. Record unmet checks as `Skipped` with "Requires
  <plan>, not licensed" (or a dedicated status, if one is approved).
- Use one consistent status for "not licensed" across all checks.
- Report "not licensed" counts separately in the summary, so they don't lower the pass rate.

## Acceptance

- [ ] On a tenant without P2, P2-gated checks are not Fail. They carry a "not licensed" reason.
- [ ] The same licence fact yields the same status across checks.
- [ ] No file outside `scope` is modified.

# T-0935 — Licence gating doesn't reach finding status, so unlicensed checks report Fail

## Report

The test tenant has Office 365 E5 and Business Premium, and neither includes Entra ID P2. In the
walk's run:
- **CA-USERRISK-001**, **CA-SIGNINRISK-001** and **ENTRA-PIM-001** are **Fail**. Their
  `licensing-overlay.json` entries (lines 5-8) require `AAD_PREMIUM_P2`.
- ENTRA-PIM-001's own evidence says "PIM not licensed".
- ENTRA-PRIVREMOTE-001 reports the same licence fact as Review, so the report contradicts
  itself.

## Cause

Licence gating is applied only to the progress display (`Common/Show-CheckProgress.ps1:108-129`).
It does not change the recorded status.

## Fix direction

- After collection, or in `Add-Setting`, compare each check's licensing-overlay requirement with
  the tenant's service plans. Record unmet checks as `Skipped` with "Requires
  <plan>, not licensed" (or a dedicated status, if one is approved).
- Use one consistent status for "not licensed" across all checks.
- Report "not licensed" counts separately in the summary, so they don't lower the pass rate.

## Acceptance

- [x] On a tenant without P2, P2-gated checks are not Fail. They carry a "not licensed" reason.
- [x] The same licence fact yields the same status across checks.
      P2-gated checks share `NotLicensed` + `Requires AAD_PREMIUM_P2, not licensed`.
      `ENTRA-PRIVREMOTE-001` is now overlay-gated to `AAD_PREMIUM_P2`, so the same central
      gate reports it as `NotLicensed` too. `tests/controls/registry-integrity.Tests.ps1`
      pins the overlay entry.
- [x] No file outside `scope` is modified.

## Fix

**`Common/SecurityConfigHelper.ps1`**
- Added `Get-CheckLicensingGate`, which reads the licence decision
  `Initialize-CheckProgress` already records in `$global:CheckProgressState.LicenseSkipped`
  (checkId -> required service plans). It returns `$null` when licence data is unavailable
  (standalone collector use), so existing standalone behaviour is unchanged.
- `Add-SecuritySetting` now checks that gate before recording a finding. When the tenant does
  not have any of the check's overlay `requiredServicePlans`, the finding is recorded as
  `NotLicensed` with `CurrentValue = "Requires <plan>, not licensed (collector reported: <original>)"`.
  The collector's observation is kept for audit context. The recorded status also feeds the
  adoption signals and `Update-CheckProgress`, so downstream consumers cannot see the old
  Fail/Pass.
- Used the existing `NotLicensed` status value: it is already in `Add-Setting`'s ValidateSet,
  already excluded from scoring in `Export-ComplianceMatrix` / `tests/Behavior/Report-Math.Tests.ps1`,
  and already rendered as "Requires Licensing" in the HTML report. No new status or semver change.

**`Common/Show-CheckProgress.ps1`**
- The pre-connection/connection licence gating is unchanged, so unlicensed checks are still
  excluded from the progress total and never stream (no double-counting).
- The gating notice now says `N checks not licensed (excluded from the pass rate)` instead of
  "skipped", and `Complete-CheckProgress` prints the same separate count.
- Added the `NotLicensed` symbol/colour (`-`, DarkYellow) and legend entry for collectors that
  emit it directly.

**Tests**
- `tests/Common/Show-CheckProgress.Tests.ps1`: overlay-gated checks land in `LicenseSkipped`,
  are excluded from the progress total, are reported separately in the gating and completion
  summaries, and a gated `Add-Setting` call records `NotLicensed` with the plan in the reason.
  Licensed tenants and the no-licence-data path leave statuses untouched.
- `tests/Entra/Get-CASecurityConfig.Tests.ps1`: with no P2, `CA-USERRISK-001` and
  `CA-SIGNINRISK-001` are `NotLicensed` (not Fail) with the reason; with P2 they still Fail.
  Non-gated CA checks keep their computed status.
- `tests/Entra/Get-EntraSecurityConfig.Tests.ps1`: with no P2, `ENTRA-PIM-001` is `NotLicensed`
  with the reason; with P2 its computed status is unchanged; non-overlay checks are untouched.
- `tests/Common/SecurityConfigHelper.Tests.ps1` re-run as a regression check (no edits).

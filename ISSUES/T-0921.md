# T-0921 — Nav items do not say what their pages do (for example Drift and Standards alignment)

## Report

The operator could not tell what several menu items do from their names. Drift and
Standards alignment look like the same thing. The operator suggested tooltips or similar.

## What the two pages actually are

- **Standards alignment** (`/standards/alignment`, EPIC-008 §3.3–3.4): a scorecard of how
  closely each tenant matches a *standards template*. It answers "how close is this tenant to
  the standard?"
- **Drift** (`/drift`, EPIC-009 §3.1): a triage queue of individual settings that have moved
  away from the applied standard, with accept, override and deny actions. It answers "what
  changed, and what do we do about it?"

They are related (alignment is the summary, drift is the work queue), but nothing in the UI
says so.

## Fix direction

- Add a one-line `description` to each `NavItem`. Show it as a tooltip on hover or focus, and
  as the page's subtitle.
- Rename items where the name misleads, for example *Standards alignment* → *Standards
  scorecard* and *Drift* → *Drift triage*.
- Cross-link the two pages ("3 tenants below target. Review drift →").

## Acceptance

- [x] Every nav item has a description that shows on hover and on keyboard focus.
- [x] The Drift and Standards alignment pages each explain how they relate to the other in one
      line.
- [x] No file outside `scope` is modified.

## Fix

**Status: fixed-unverified** (2026-11-20)

### Changes

- `portal/web/src/components/shell/AppNav.tsx`
  - `NavItem` now requires a `description`; all 116 nav items and the three parked items have a
    one-line description.
  - Each link renders the description as its `title` fallback, as an `aria-describedby`
    referenced `role="tooltip"` element (read by assistive tech), and as a styled tooltip that
    appears on hover and on keyboard focus (`:focus-within`).
  - Renamed `Standards alignment` → `Standards scorecard` and `Drift` → `Drift triage`; routes
    are unchanged.
- `portal/web/src/app/drift/page.tsx`
  - Heading renamed to `Drift triage`; the nav description is now the page subtitle.
  - Added the cross-link line: drift triage is the work queue, the standards scorecard is the
    summary.
- `portal/web/src/app/standards/alignment/page.tsx`
  - Default heading renamed to `Standards scorecard`; the nav description is now the subtitle.
  - Added the cross-link line: the scorecard is the summary, triage deviations in the drift
    queue.

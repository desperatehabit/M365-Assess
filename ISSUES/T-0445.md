External address · Type · Hidden from GAL · Last modified), row actions (`View`, `Edit`,

→ Administration → Contacts* per §3. Theme and tokens come from `02-ui-design.md`; no colour
literals (`05-programming.md` §4).

state. A Vitest/Testing-Library test covers loading, loaded, error, and an import-results render.

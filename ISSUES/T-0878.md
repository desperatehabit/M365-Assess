# T-0878 — Drift deviation remediate endpoint is missing

## Report

EPIC-009 SPEC §6 and US-6 define `POST /v1/drift/deviations/{id}/remediate`, but no such route
exists. The triage routes only expose accept/override (`portal/bff/src/routes/drift-triage.ts:26-27`)
and deny (`portal/bff/src/routes/drift-deny.ts:28`); a search of `portal/bff/src/routes/` finds no
`/remediate` path, and `portal/web/src/lib/driftApi.ts` has no remediate call. A deviation cannot be
remediated from the portal.

## Acceptance

- [ ] `POST /v1/drift/deviations/{id}/remediate` exists, is authorized, and enqueues the real
      remediation apply job.
- [ ] The drift UI exposes a remediate action that calls the endpoint.
- [ ] A route test covers the remediate path and fails without it.
- [ ] No file outside `scope` is modified.

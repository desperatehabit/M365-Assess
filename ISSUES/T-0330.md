# T-0330 — Deployment and enrollment status pages

## Report

EPIC-017 SPEC.md §3.6 and §2 US-7 require deployment/enrollment status dashboards with
per-device state and filters, and §6 fixes `GET /v1/tenants/{id}/apps/status`. §3.5 also says
status pages show enrollment progress for the Apple/Android profiles built in T-0329.

Deliver an `intune-app-status.ts` read route that aggregates app install state (from the T-0321
app data / Graph) and enrollment progress per device, and a status page + `DeploymentStatusTable`
component with per-device state and filters. The route is read-only and tenant-scoped.

## Acceptance

- [ ] `GET /v1/tenants/{id}/apps/status` returns app deployment and enrollment state per device with filters.
- [ ] The status page renders per-device state for both app deployments and enrollment profiles.
- [ ] The route is read-only; the T-0015 guard test still passes.
- [ ] Tests cover the route and component and fail without them.
- [ ] No file outside `scope` is modified.

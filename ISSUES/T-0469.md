# T-0469 — Message encryption (IRM/OME) read, config page, and gated template changes

## Report

EPIC-024 SPEC.md §2 US-5, §3.5, §4.3, and §8 define message encryption: view IRM/OME
configuration and templates, manage OME templates where supported, read config, and apply
template changes through EPIC-006; changes are audited. §6 exposes `GET`/`PUT`
`/v1/tenants/{id}/mail/encryption`.

Deliver a `Get-MessageEncryption.ps1` handler (entrypoint `get-message-encryption.ps1`) that
reads the IRM/OME configuration and templates, plus `GET` and `PUT` routes where `PUT` routes
template changes through the EPIC-006 gated executor (T-0108) with audit, and an
`EncryptionPanel` page rendering the config and template editor. The `GET` requires
`mailtools.read`; the `PUT` requires `mailtools.write` + `Remediation.Apply`. Extend
`portal.v1.yaml`.

## Acceptance

- [ ] The page renders IRM/OME configuration and templates from the read API.
- [ ] A `PUT` routes through EPIC-006, captures before/after, and is audited.
- [ ] A caller without the write permission receives a structured error.
- [ ] A test covers read and gated write and fails without it.
- [ ] No file outside `scope` is modified.

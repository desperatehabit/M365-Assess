# T-0865 — Mount EPIC-035 Backup routes and invoke retention/replication

## Report

The EPIC-035 factories (`createBackupRoutes`, `createBackupSettingsRoutes`,
`createBackupsRestoreRoutes`) exist under `portal/bff/src/routes/` and are tested, but
`portal/bff/src/app.ts` imports none of them and there is no adapter under `portal/bff/src/adapters/`,
so the endpoints 404. Migration `0043_backups.sql`, `db/src/repository.ts` / `sqlite-repository.ts`,
and the UI (`app/backup/page.tsx`, `components/backup/RestoreWizard.tsx`, `app/backup/settings/page.tsx`)
exist.

Functional gap (SPEC §4.3, §10): `portal/bff/src/backup/retention.ts:114` (`pruneExpiredBackups`) and
`portal/bff/src/backup/replication.ts:109` (`replicateLatestBackup`) are implemented but have no
non-test callers — no route, scheduler, or job invokes them, so backups are neither pruned nor
replicated.

## Acceptance

- [ ] Every EPIC-035 SPEC §6 endpoint returns a non-404 response from a running BFF.
- [ ] Backup list/create/download/delete/restore and settings run against real storage.
- [ ] Retention pruning and replication are invoked by a scheduler or job and covered by a test.
- [ ] No file outside `scope` is modified.

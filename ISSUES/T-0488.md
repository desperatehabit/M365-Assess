# T-0488 — Site browser: libraries, permissions, external users, admin-center link

## Report

EPIC-025 SPEC.md §2 US-5, §3.4, and §4.3 define the site browser: per-site libraries, items, and
permissions; external-user listing; a link into the SharePoint admin center; read-only
enumeration with permission changes handed to EPIC-027. §6 exposes `GET
/v1/tenants/{id}/sharepoint/sites/{siteId}/browse`. §11 item 4 is resolved (adopted): v1
**implements** the read-only browser and deep-links to the SPO admin center for advanced
actions not in v1 (site collection upgrade, term store, tenant-level sharing settings), rather
than reimplementing those admin-center surfaces.

Deliver a `Get-SiteBrowser.ps1` handler (entrypoint `get-site-browser.ps1`) returning libraries,
items, permissions, and external users, plus the read route validating `sharepoint.read` and
tenant scope, and the `SiteBrowser` component rendering the lists and the admin-center deep
link. Permission edits are not performed here; expose the EPIC-027 hand-off. Extend
`portal.v1.yaml`.

## Acceptance

- [ ] The browser lists libraries, permissions, and external users for a site.
- [ ] A deep link to the SPO admin center is rendered for advanced actions.
- [ ] A caller without `sharepoint.read` is refused; the browser performs no writes.
- [ ] A test covers library/permission listing and fails without it.
- [ ] No file outside `scope` is modified.

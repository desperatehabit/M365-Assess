# T-0669 — Domain Analyser UI

## Report

EPIC-034 SPEC.md §3.2 defines the **Domain Analyser** page: a per-domain panel reusing the
report's `.dns-*` styles, showing MX (records + provider), SPF (record, lookup count,
`-all`/`~all`), DKIM (selector1/selector2 presence + enabled state), DMARC (record, policy,
rua/ruf, alignment), and MTA-STS / TLS-RPT (presence + policy), each with a `status-badge` and a
plain-language explanation. §3.3 adds the recommendations list with remediation links; §3.4 adds
the change history.

Build the analyser route and the `DnsPanel`, `DnsRecommendations`, and `DnsHistoryChart`
components against the T-0665 check/history and T-0666 recommendations endpoints, extending the
T-0668 `domainsApi.ts` client. Reuse the report's `.dns-*` classes for visual continuity and
report theme tokens only; no colour literals.

## Acceptance

- [ ] The panel renders all six record families with a `status-badge` and explanation.
- [ ] Recommendations render with working remediation links; a clean domain shows the empty state.
- [ ] The history chart renders stored checks over time.
- [ ] A test covers the component states and fails without it; only theme tokens and the
      `.dns-*` classes are used.
- [ ] No file outside `scope` is modified.

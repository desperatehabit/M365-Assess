# T-0954 — COMPLIANCE-DLP-001 counts simulation-mode DLP policies as enabled

## Report

- `Get-ComplianceSecurityConfig.ps1` (around line 91) counts policies with `Enabled -eq $true`.
- A DLP policy in simulation (`Mode = TestWithNotifications` or `TestWithoutNotifications`) is
  `Enabled` but does not enforce anything.
- Observed on the live tenant: three DLP policies, one in `TestWithNotifications` (the default
  Copilot interactions policy). The run reported "3 enabled (of 3 total)"; two enforce.
- The same `Enabled` test may apply to DLP-002 (Teams coverage) and DLP-003 (workload coverage).

## Fix direction

- Count a policy as enforcing only when `Mode -eq 'Enable'`; report simulation-mode policies
  separately ("2 enforced, 1 in simulation, of 3").
- Apply the same rule to the DLP coverage checks.

## Acceptance

- [ ] A simulation-mode policy is not counted as enforced, and is listed as simulation.
- [ ] Tests cover `Enable`, `TestWithNotifications` and `Disable`, and fail without the change.

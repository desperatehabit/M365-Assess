# T-0609 — Fleet Secure Score overview UI

## Report

EPIC-031 SPEC.md §2 US-6 and §3.5 define **Secure Score — Table Overview**: an all-tenants score
table/card grid with trend sparklines, sortable, respecting RBAC scope. Nav is *Tenant
Administration → Secure Score* per
[`cipp-ui-inventory.md`](../../docs/portal-specs/99-reference/cipp-ui-inventory.md) §3. Theme per
[`02-ui-design.md`](../../docs/portal-specs/00-guides/02-ui-design.md).

Deliver the fleet page against the T-0606 route: a sortable table/card grid of tenants with current
score/percentage and a sparkline from the returned trend series, each row linking to the T-0607
tenant report. The list reflects the caller's scoped tenants; a tenant with no snapshot shows an
explicit empty state. No new server logic.

## Acceptance

- [ ] The overview lists the caller's visible tenants with score/percentage and a sparkline.
- [ ] Columns are sortable and each row links to the tenant report page.
- [ ] Tenants without a snapshot show an explicit empty state.
- [ ] A test covers the fleet rendering and sort/empty paths and fails without it.
- [ ] No file outside `scope` is modified.

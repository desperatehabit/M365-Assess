# T-0628 — Search coverage and directory audits UI

## Report

EPIC-032 SPEC.md §3.3 defines the **Search Coverage** page: which tenants have audit-log
ingestion enabled, their search windows, and gaps, with gaps linking to the `COMPLIANCE-AUDIT-001`
remediation. §3.4 defines the **Directory Audits** page: Timestamp, Activity, Initiated by,
Target, Result, filtered by category and date. Both live under *Tenant Administration → Audit
Logs*.

Build the two routes and the `CoverageTable` / `DirectoryAuditsTable` components against the
T-0624 coverage and T-0622 directory endpoints, extending the T-0627 `auditApi.ts` client. Gaps
render as `.status-badge` chips that link to the finding's remediation in EPIC-006. Use report
theme tokens only.

## Acceptance

- [ ] Coverage renders per-tenant ingestion state, search windows, and gaps, with a working
      remediation link.
- [ ] Directory audits render the §3.4 columns and filter by category and date.
- [ ] A test covers the component states and fails without it; only theme tokens are used.
- [ ] No file outside `scope` is modified.

# T-0785 — Tenant lookup API and page

## Report

EPIC-040 SPEC.md §3.2, §6 (US-3): `GET /v1/tenant-lookup` takes a domain or tenant ID and
returns tenant ID, name, default domain, verified domains, region, and whether the tenant is in
the portal. Page title **Tenant Lookup**.

Build `tenant-lookup-service.ts` that resolves a domain/ID against Graph's tenant endpoints and
cross-checks the portal's own tenant store. This depends on the tenant/credential model authored
in **EPIC-002** (prose; EPIC-002's tickets are not referenced directly). `GET /v1/tenant-lookup`
requires `tools.read`; a caller scoped away from a tenant must not receive that tenant's
details (intersect with `UserScope`, T-0743). The page shows the fields and an "in portal" chip.

## Acceptance

- [ ] `GET /v1/tenant-lookup` returns the §3.2 fields for a domain or tenant ID.
- [ ] The "in portal" flag is true only when the tenant exists in the portal store.
- [ ] A caller outside the tenant's scope is denied rather than shown details.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

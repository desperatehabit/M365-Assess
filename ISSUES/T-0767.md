# T-0767 — Save template to GitHub (opt-in, deferred behind the EPIC-041 GitHub integration)

## Report

EPIC-039 SPEC.md §3.4, §4.2, §6 (US-4): from a template (standards/CA/Intune/custom test),
`Save to GitHub` opens a dialog (repository pick from configured repos, commit message) and
commits the template file **only when a GitHub integration is enabled**.

§11 open question 1 is **resolved (adopted): local-only catalog first**; the GitHub flow is a
later **opt-in**, and it reuses the GitHub integration authored in EPIC-041 (T-0802) rather
than implementing its own transport. This ticket is therefore **deferred/optional** until that
integration is un-parked: it delivers the opt-in dialog, the gated
`POST /v1/template-library/{id}/save-to-github` route, and an adapter seam that fails closed
with a structured error when no integration is configured. Only `templates.write` plus the
GitHub integration grants access; commits are audited.

## Acceptance

- [ ] The `Save to GitHub` action is hidden/disabled until a GitHub integration is configured.
- [ ] With an integration enabled, the commit route writes the template and records the commit in the audit log.
- [ ] Auth/conflict failures surface as structured errors; the default with no integration is a no-op that fails closed.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

# T-0089 — Executive report button, preview dialog, and report history surfaces

## Report

EPIC-005 SPEC.md §3.1: the **Executive Report** button opens a `Dialog` with an inline PDF
preview and a **Download** action. §3.3 adds the **Generated Reports** and **Templates** tabs:
templates expose Edit/Clone/Delete/Generate; generated reports show status, tenant, template,
created, and a download link. §4.1 requires the download action to be audited (server-side, via
T-0084).

Deliver:

- `ExecutiveReportButton` + `PdfPreviewDialog` using the render API from T-0084.
- `/reports` page with the Generated Reports / Templates tabs and their row actions and download
  links.
- Tests for preview open/download, history rendering, and template row actions.

Note: the button is also mounted in the EPIC-004 dashboard toolbar (cross-ref in prose); this
ticket provides the component, EPIC-004 places it.

## Acceptance

- [ ] The executive button renders a preview and downloads the PDF.
- [ ] The generated-reports tab lists reports with working download links.
- [ ] The templates tab supports Edit, Clone, Delete, and Generate.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

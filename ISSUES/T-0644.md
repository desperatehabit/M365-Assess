# T-0644 — Licence pricing API and global seed with per-tenant override

## Report

EPIC-033 SPEC.md §3.3 defines the **License Pricing** page: an editable pricing table per SKU and
currency, used for cost columns, with defaults seeded from a CSV. §6 exposes
`GET`/`PUT /v1/license-pricing`. Pricing edits require `CIPP.Admin.*` (SPEC §7). Resolved §11.2
adopts **global seed defaults with per-tenant override**: the seed is a committed CSV, and a
tenant may override a SKU price for its own cost view; the global row applies otherwise.

Build the `GET`/`PUT` routes over T-0641's repository, `license-pricing-seed.ts` to parse and
upsert the seed CSV at bootstrap, and the effective-price resolution used by T-0642. Editing a
price writes an `AuditEvent`. Missing pricing is surfaced honestly (SPEC §9) and never replaced
with a zero. Extend `portal.v1.yaml`.

## Acceptance

- [ ] `GET` returns the effective pricing (tenant override else global); `PUT` upserts an
      override or global row and is admin-gated.
- [ ] The seed CSV populates global defaults once and does not clobber an operator edit.
- [ ] Pricing edits write an `AuditEvent`.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

# T-0926 — Exchange Online and Purview connections pass the tenant GUID as `-Organization`, so 10 collectors never run

## Report

In the walk's portal-started run, every Exchange Online and Purview collector was skipped. The
assessment log has two ERROR lines:

```
Failed to connect to ExchangeOnline: Organization cannot be a Guid, please enter the name of the tenant instead.
Failed to connect to Purview: Organization cannot be a Guid, please enter the name of the tenant instead.
```

What was skipped: 5 Email collectors, Defender Policies, Defender Security Config, DLP,
Compliance Security Config and Purview Retention. The run has no CSV for any of them, and it
still finished `succeeded` (see T-0929).

## Cause

- `Common/Connect-Service.ps1:313` (EXO) and `:351` (IPPS) set `Organization = $TenantId`.
- On the Windows certificate-**thumbprint** path, `Set-ExchangeAppOnlyAuth` (around line 194)
  never replaces it with the tenant's initial domain. `Resolve-InitialDomain` runs only on the
  certificate-object path.
- `Orchestrator/Connect-RequiredService.ps1:195` overwrites `$ctx.Tenant.TenantId` with the
  GUID, although `InitialDomain` is available.
- The portal worker passes `Context.Tenant.TenantId` (the GUID) as `-TenantId`
  (`M365Portal.Workers.psm1:270`), although the context already carries `DefaultDomain` (the
  `.onmicrosoft.com` domain).

## Fix direction

- Always resolve `-Organization` to the initial `.onmicrosoft.com` domain for EXO and IPPS app-only
  connections, on every certificate path. Use `InitialDomain` or `DefaultDomain` when known, and
  otherwise look it up from Graph `/organization` after the Graph connection.
- Never use a GUID for `-Organization`. Check for one and fail early with a clear message.

## Acceptance

- [ ] A portal run with certificate-thumbprint auth connects to EXO and IPPS, and every Email,
      Defender and Purview collector produces output.
- [ ] Tests cover the thumbprint, certificate-object and CLI paths: `-Organization` is a domain,
      never a GUID.
- [ ] No file outside `scope` is modified.

# T-0881 — User Templates management page is missing

## Report

EPIC-011 SPEC §3.5 specifies a User Templates surface (create/edit reusable onboarding templates).
The backend exists — `portal/bff/src/routes/user-templates.ts` mounted in `app.ts`, and
`portal/web/src/lib/offboardingApi.ts:193` exposes `listUserTemplates` — but it is used only inside
the offboarding wizard. There is no `portal/web/src/app/**/user-templates` route and no create/edit
UI, and the nav has no entry.

## Acceptance

- [ ] A User Templates page exists where templates can be listed, created, and edited.
- [ ] It calls the mounted user-template endpoints.
- [ ] A component test covers rendering and a create/edit round trip.
- [ ] No file outside `scope` is modified.

# T-0729 — Branding page with live preview, Logbook, and Diagnostics UI

## Report

EPIC-037 SPEC.md §3.2 defines **Branding** (primary/secondary colour, footer text, cover footer
text, show footer, show page numbers, watermark text/enabled, logo + cover upload, presets,
per-report-type defaults) with a **live preview** on a sample report/PDF; §4.2 is edit → preview →
save, and §9 requires upload validation feedback. §3.5 defines **Logbook** (searchable log with
detail and correlation IDs, filters, export) and **Diagnostics** (container/worker health, cache
status, timers) under *Advanced*.

Deliver the branding page with `BrandingForm` and `BrandingPreview` wired to the T-0724 API
(previewing an unsaved draft, surfacing T-0723 upload validation errors), plus the Logbook and
Diagnostics pages wired to the T-0727 APIs. Theme tokens only with no colour literals
(`05-programming.md` §4). This completes the surfaces EPIC-037 requires; custom data (US-6) is
deferred.

## Acceptance

- [ ] The branding form edits every §3.2 field and shows a live preview before saving.
- [ ] An invalid upload is rejected in the UI with the validator's message; a valid one previews.
- [ ] Logbook renders filters/search/export; Diagnostics renders health, cache, and timers.
- [ ] A test covers the change and fails without it; only theme tokens are used.
- [ ] No file outside `scope` is modified.

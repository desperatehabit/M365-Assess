# T-0728 — Application Settings, Features, and Preferences UI

## Report

EPIC-037 SPEC.md §3.1 defines **Application Settings** with the trimmed CIPP tab pattern (General,
Branding, Permissions, Notifications, Features, Security, Integrations) — Branding is T-0729, and
Permissions/Notifications/Integrations are hand-offs to EPIC-038/EPIC-029/EPIC-041 (prose).
§3.3 defines **Features** (toggle list with description, scope, effect) and §3.4 defines
**Preferences** (General, Navigation, theme/density/text scale, portal links), with §4.3 mirroring
per-user prefs to `localStorage` for first-paint theming.

Deliver the settings, features, and preferences routes and components wired to the
T-0722/T-0725/T-0726 APIs. Feature toggles render from the same flag source the API enforces so the
nav cannot show a disabled feature. Preferences write through to the API and mirror to
`localStorage`. Theme tokens only, no colour literals (`05-programming.md` §4). Branding and
Logbook/Diagnostics UI are T-0729.

## Acceptance

- [ ] Settings tabs render and persist valid changes through `PUT /v1/settings`; invalid input is surfaced.
- [ ] Feature toggles persist and immediately gate nav, matching API enforcement.
- [ ] Preferences persist for the user and mirror to `localStorage` for first paint.
- [ ] A test covers the change and fails without it; only theme tokens are used.
- [ ] No file outside `scope` is modified.

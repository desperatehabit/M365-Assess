# T-0913 — CI does not build or test the portal

## Report

No workflow in `.github/workflows/` mentions `portal/`. The only `npm run build` in `ci.yml`
(line ~126) builds the HTML report app. As a result:

- The roughly 6,200 Vitest tests in `portal/` (contracts, db, bff, web) never run in CI.
- `next build` is never run. On 2026-11-17 it failed on main's pages: about 80 pages call
  `useSearchParams()` with no Suspense boundary, which breaks the production prerender. The
  fix (a boundary in `app/layout.tsx`) landed with the Phase 1 PR, but nothing stops a
  regression.

"CI green" therefore says nothing about the portal, and the Phase 2 gate depends on it.

## Fix direction

Add a `portal` job on `ubuntu-latest` with Node 20: `npm ci` in `portal/` (allowing the
`better-sqlite3` install script), `npm run typecheck`, `npm run build`, `npm test`. Make it a
required check.

## Acceptance

- [ ] A PR that breaks a portal test or `next build` fails CI.
- [ ] The job is listed as required on `main`.
- [ ] No file outside `scope` is modified.

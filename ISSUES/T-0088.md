# T-0088 — Report Builder page

## Report

EPIC-005 SPEC.md §3.2 defines the builder: a **left canvas**, a **right rail** (*Report Settings*,
*Page Setup & Branding*), and primary buttons `Save template`, `Schedule`, `Download PDF`,
`Preview PDF` (dialog + download), `Add block`. Blocks come from the T-0081 contract; per-block
controls are move up / move down / remove / refresh data / revert to live data. `02-ui-design.md`
§6 requires the page use report tokens, and ADR-0016 requires preview/download to use the
server-side render path (T-0084).

Deliver:

- The builder route and components: canvas rendering all six block types, the settings rail, and
  block controls.
- Add-block picker constrained to the v1 block set; Save template calls T-0085; Preview/Download
  call T-0084; Schedule links to EPIC-007 (prose cross-ref, not implemented here).
- Tests for add/move/remove, settings edit, and a successful save/round-trip.

## Acceptance

- [ ] All six block types can be added, moved, and removed on the canvas.
- [ ] `Save template` persists via the template API and reloads intact.
- [ ] `Preview PDF` / `Download PDF` call the render API; `Schedule` hands off to EPIC-007.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

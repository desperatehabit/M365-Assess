# T-0870 — Mount EPIC-040 Graph Explorer & Admin Tools routes

## Report

The EPIC-040 route factories live under `portal/bff/src/tools/` and none is imported by
`portal/bff/src/app.ts`:

- `createGraphExplorerRoutes` (`tools/graph-explorer-routes.ts:169`)
- `createGraphPresetRoutes` (`tools/graph-preset-routes.ts:93`)
- `createTenantLookupRoutes` (`tools/tenant-lookup-routes.ts:71`)
- `createAppApprovalRoutes` (`tools/app-approval-routes.ts:136`)
- `createBreachLookupRoutes` (`tools/breach-lookup-routes.ts:126`)
- `createGeoIpRoutes` (`tools/geoip-routes.ts:81,112`)

so every SPEC §6 endpoint 404s. Additional gaps:

- Worker `invoke-graph-request.ps1` is named by `tools/graph-explorer-service.ts:91`
  (`GRAPH_EXPLORER_WORKER_ENTRYPOINT`) and invoked at `:281`, but no wrapper or implementation exists
  under `portal/workers/`.
- `ConsentDecision` (SPEC §5, §8) is held only in memory:
  `tools/app-approval-service.ts:4` ("persisted … in memory") and `:133`
  (`const decisions: ConsentDecision[] = []`); there is no migration or repository.
- Tenant Breach Lookup and Breach Lookup pages are missing; `app/tools/` has only
  `app-approval`, `tenant-lookup`, `graph-explorer`, `ip-database`, and `domain-check`.

## Acceptance

- [x] Every EPIC-040 SPEC §6 endpoint returns a non-404 response from a running BFF.
- [x] `invoke-graph-request.ps1` exists and backs the Graph Explorer.
- [x] `ConsentDecision` persists through SQLite (no in-memory array).
- [x] The Tenant Breach Lookup and Breach Lookup pages exist.
- [x] No file outside `scope` is modified.

## Fix

The six EPIC-040 route factories were mounted in `createApp`. The Graph
Explorer now runs `invoke-graph-request.ps1` (wrapper plus
`Invoke-GraphRequest.ps1`), which re-checks the method/host allowlist and returns
Graph's status/body envelope. Graph presets persist through the existing SQLite
repository. `ConsentDecision` moved to migration `0130_consent_decisions.sql`
and `SqliteConsentDecisionRepository`; the approval service now requires that
store. Tenant lookup uses the portal tenant store plus public OpenID tenant
resolution, breach lookup remains fail-closed until EPIC-041 registers a
provider, and the individual domain check reuses the EPIC-034 DNS analyser.
The Breach Lookup and Tenant Breach Lookup pages were added under
`app/tools/`. `app-epic040-mounts.test.ts` probes every endpoint through the
real app.

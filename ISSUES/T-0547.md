# T-0547 — Incident detail tabs and triage actions UI

## Report

EPIC-028 SPEC.md §3.2 requires the incident detail with tabs **Overview** · **Alerts** ·
**Entities** · **Timeline** · **Notes** and triage actions in the header. §3.1 requires the bulk
assign/set-status confirmation. These render the T-0545 detail API and drive the T-0546 actions
API.

Deliver the incident detail route rendering `IncidentTabs` (Overview, Alerts, Entities, Timeline,
Notes) against T-0545, plus `TriagePanel` for assign/status/classify/comment in the header and
`BulkTriageDialog` enforcing the confirmation gate from the Incidents list (T-0544). A
Vitest/Testing-Library test covers tab rendering, a triage action round-trip, and the bulk
confirm gate.

## Acceptance

- [ ] All five tabs render their content from the detail API, including portal notes.
- [ ] Header triage actions (assign/status/classify/comment) call T-0546 and refresh the view.
- [ ] Bulk triage cannot proceed without the confirmation dialog.
- [ ] A test covers the tabs, a triage action, and the bulk confirm gate and fails without it.
- [ ] No file outside `scope` is modified.

# T-0875 — Report bundle is not assembled and the executive report renders empty sections

## Report

Three gaps in the mounted EPIC-005 report path:

1. `POST /v1/reports/{id}/bundle` (`portal/bff/src/routes/reports.ts:332-376`) returns
   `{ artifacts }` — a listing only. SPEC §3.4 / §10 require a bundled download containing the
   HTML/XLSX/JSON artifacts. No web caller consumes the endpoint either.
2. The executive render payload hardcodes `secureScore: {}` and `actionBuckets: {}`
   (`portal/bff/src/adapters/reports.ts:162-163`; asserted empty in `reports.test.ts:162-163`), so the
   executive report's Secure Score and Action bucket sections render empty even when data exists
   (`portal/bff/src/domain/reports/html.ts:112-131`).
3. `createUnavailableTemplateRender` (`adapters/reports.ts:193-204`), a 501 render-unavailable stub,
   is defined but referenced by no mount — dead placeholder code.

## Acceptance

- [ ] `/v1/reports/{id}/bundle` returns an assembled bundle containing all selected artifacts.
- [ ] The executive report renders live Secure Score and Action bucket data.
- [ ] The dead `createUnavailableTemplateRender` stub is removed or wired.
- [ ] A test covers the bundle contents and the populated executive sections.
- [ ] No file outside `scope` is modified.

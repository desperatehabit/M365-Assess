# T-0447 — Contact template deploy with variables and partial-failure reporting

## Report

EPIC-023 SPEC.md §4.2 defines template deploy: resolve template + variables → plan → apply per
tenant, with partial failures reported. §6 exposes `POST /v1/contact-templates/{id}/deploy`.
§8 requires writes through EPIC-006.

Deliver a `Deploy-ContactTemplate.ps1` handler (entrypoint `deploy-contact-template.ps1`) that
substitutes the per-target variables into the template, builds a plan preview, and applies
valid targets through the EPIC-006 gated executor (T-0108), returning a per-target result. Add
the deploy route (validates `contacts.write` + `Remediation.Apply`) and a deploy dialog that
collects the variable values and shows the plan and per-target outcomes. Extend `portal.v1.yaml`.

## Acceptance

- [ ] Deploy previews the resolved contacts before apply; nothing is written on preview.
- [ ] Per-target success/failure is returned; a partial failure does not hide the successes.
- [ ] Applied targets route through EPIC-006 and are audited.
- [ ] A test covers variable resolution and partial failure and fails without it.
- [ ] No file outside `scope` is modified.

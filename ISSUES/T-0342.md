# T-0342 — Device detail API (overview, hardware, software, policies, encryption)

## Report

EPIC-018 SPEC.md §2 US-2 and §3.2 define the **Device detail** tabs: Overview (compliance,
ownership, OS, serial, enrollment) · Hardware · Software · Policies (applied config/compliance) ·
Encryption (BitLocker status/keys) · Actions (history). §6 fixes
`GET /v1/tenants/{id}/devices/{deviceId}` for detail.

Deliver a read-only `Get-ManagedDevice.ps1` worker handler + `get-managed-device.ps1` entrypoint
that assembles the tab payloads from Graph (device, hardware inventory, detected software, applied
policies, encryption state) and the BFF detail route behind `devices.read`. The encryption tab
reports BitLocker **status** here; key retrieval is T-0346. Action history is read from T-0343, not
assembled here. No writes.

## Acceptance

- [ ] `GET /v1/tenants/{id}/devices/{deviceId}` returns the §3.2 tab data for a device.
- [ ] Hardware, software, and policy sections come from Graph; encryption reports BitLocker status only.
- [ ] The handler performs no writes; a device outside the caller's scope is refused.
- [ ] Tests cover the route and worker and fail without them.
- [ ] No file outside `scope` is modified.

# T-0689 — Backups page, restore wizard, and backup settings UI

## Report

EPIC-035 SPEC.md §3.1-§3.3 define the UI: **Backups** (nav *Tenant Administration → Backup*,
instance backup under *CIPP → Settings*) with a table of Name · Type · Scope · Created · Size ·
Location, row actions `Download`/`Restore`/`Delete`, and primary `New backup`; the **Restore**
wizard (pick backup → full/selective scope → preview changes → destructive confirm); and
**Backup Settings** (retention, schedule, replication target). Theme per `02-ui-design.md`.

Deliver the backup routes and components wired to the T-0685/T-0687/T-0688 APIs, reusing the report
theme tokens with no colour literals (`05-programming.md` §4). The wizard must render the T-0686
preview diff before enabling the destructive confirm. `Schedule` is EPIC-007's scheduler picker and
is consumed here, not re-implemented.

## Acceptance

- [ ] The table renders every §3.1 column and the Download/Restore/Delete/New backup actions.
- [ ] The restore wizard shows the preview and blocks confirm until the user acknowledges it.
- [ ] The settings page reads and writes retention and replication values.
- [ ] A test covers the table and wizard states and fails without it; only theme tokens are used.
- [ ] No file outside `scope` is modified.

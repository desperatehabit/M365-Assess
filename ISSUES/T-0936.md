# T-0936 — All 11 Power BI checks are Review after a 404, and the message blames the wrong cause

## Report

In the walk's run, all 11 Power BI checks are **Review**. The collector's call to
`admin/tenantSettings` (`Get-PowerBISecurityConfig.ps1:58`) returned **404 Not Found**, and the
message tells the operator to check the Power BI admin role.

## Likely cause (to confirm)

A 404, as opposed to a 401 or 403, points to a wrong endpoint rather than a missing role. Tenant
settings are believed to be served from the Fabric admin API
(`https://api.fabric.microsoft.com/v1/admin/tenantsettings`), not the Power BI REST path the
collector calls.

## Fix direction

- Confirm the endpoint with a raw call, then correct it.
- Make the error message match the HTTP status: 401 or 403 means a permission or role problem,
  and 404 means an endpoint or API problem.
- Record the failure as a collector issue or sentinel (T-0930), so the run is `partial` (T-0937).

## Acceptance

- [ ] On a tenant where the app has the required access, the Power BI checks record real
      values.
- [ ] A 404 and a 403 give different, accurate messages.
- [ ] No file outside `scope` is modified.

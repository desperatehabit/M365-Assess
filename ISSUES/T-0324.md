# T-0324 — App assignment with plan preview and audit

## Report

EPIC-017 SPEC.md §4.2 requires assignment to groups with intent
(required/available/uninstall) behind a **plan preview** before apply, and §9 names assignment
mistakes as a risk mitigated by preview + confirmation. §6 fixes
`POST /v1/tenants/{id}/apps/{appId}/assign`.

Deliver `Set-IntuneAppAssignment.ps1` + `set-intune-app-assignment.ps1` and the BFF route behind
the T-0108 gated-write seam. The worker resolves the requested group + intent changes into a plan
(added/removed assignments with current state), applies on confirm, and captures before/after.
The app is validated against the T-0321 app-type registry; every write is audited.

## Acceptance

- [ ] The assign route returns a plan listing group intent changes before any write.
- [ ] Apply creates/updates assignments and records before/after; the app must exist in the T-0321 registry.
- [ ] Every assignment change is audited with actor and result.
- [ ] Tests cover the worker and route and fail without them.
- [ ] No file outside `scope` is modified.

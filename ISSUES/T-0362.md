# T-0362 — Defender Status page UI

## Report

EPIC-019 SPEC.md §3.1 and §2 US-1 require a **Defender Status** page rendering cards/table per
policy area (AV, EDR, ASR, compliance, firewall, exclusions) with current state vs recommended,
reusing the T-0361 status route. Findings tie to the module's Defender checks and to standards
(EPIC-008). The nav entry is *Security & Compliance → Defender → Status*.

Deliver the status page and a `DefenderStatusCards` component that renders a card per policy area
with current vs recommended state, a pass/fail/review badge, and a link to the corresponding
standard finding. Kit tokens only; read-only.

## Acceptance

- [ ] The page renders one card per policy area with current vs recommended state.
- [ ] Unsupported areas are shown as such, not as failing.
- [ ] Each card links to the related finding/standard where available.
- [ ] Component tests cover rendering of pass/fail/review and fail without them.
- [ ] No file outside `scope` is modified.

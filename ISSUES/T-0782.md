# T-0782 — Graph Explorer page (request editor and response viewer)

## Report

EPIC-040 SPEC.md §3.1 (US-1): page **Graph Explorer** with a method + URL + body editor, a
**Run** button, and a response viewer (formatted JSON, status, headers, duration). Write
methods are visually marked as elevated and warn that they are audited (§3.1, §8).

Build the page against the T-0781 API using theme tokens. `GraphRequestEditor` owns method
selection, URL, and body with JSON validation; `GraphResponseViewer` renders status, headers,
duration, and collapsible formatted JSON. Provide a "Save as preset" affordance whose wiring to
the presets API is completed in T-0784; the page renders a preset slot component that T-0784
supplies. Keep all request state client-side; no tenant call happens without an explicit Run.

## Acceptance

- [ ] The page runs a request and renders formatted JSON with status, headers, and duration.
- [ ] Write methods are marked elevated and carry an "audited" warning before Run.
- [ ] Malformed JSON in the body is rejected inline without sending a request.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

# T-0426 — Quarantine submit-for-review with tracked status

## Report

EPIC-022 SPEC.md §2 (US-4), §3.3, §4.2 step 4, and §6 require a message to be submitted for
review, routing to Microsoft with status tracked. Resolved §11.1 fixes the transport: **EXO
quarantine cmdlets where they support submit, else Graph** (the same resolution as T-0424).

Deliver `POST /v1/tenants/{id}/quarantine/{messageId}/submit` on `quarantine.ts` and the
`Submit-QuarantineReview.ps1` worker job plus `submit-quarantine-review.ps1` entrypoint. The
submission routes through the EPIC-006 gate (T-0107), records a `QuarantineAction` (T-0424) with
`action: submit` and its status, and writes an `AuditEvent`; a subsequent status refresh updates
the tracked state. Extend `portal.v1.yaml`.

## Acceptance

- [ ] Submitting a message for review returns a tracked submission status.
- [ ] The submission records a `QuarantineAction` and an `AuditEvent`.
- [ ] A status refresh reflects the current review state, not a stale value.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

# T-0489 — OneDrive usage and sharing overview

## Report

EPIC-025 SPEC.md §2 US-6 and §3.5 define the **OneDrive** page: usage and sharing per user,
with bulk sharing-link removal handed to EPIC-027. §6 exposes `GET /v1/tenants/{id}/onedrive`.
Sites/OneDrive data are read live from Graph.

Deliver a `Get-OneDriveUsage.ps1` handler (entrypoint `get-onedrive-usage.ps1`) returning
per-user OneDrive usage and sharing state, plus the read route validating `sharepoint.read` and
tenant scope, and the OneDrive page rendering `OneDriveTable` with a hand-off affordance to
EPIC-027 for bulk sharing-link removal (no removal implemented here). Extend `portal.v1.yaml`.

## Acceptance

- [ ] `GET /v1/tenants/{id}/onedrive` returns per-user usage and sharing state, paginated.
- [ ] The page renders the table and exposes the EPIC-027 hand-off without performing removal.
- [ ] Results are tenant-scoped; a caller without `sharepoint.read` is refused.
- [ ] A test covers listing and fails without it.
- [ ] No file outside `scope` is modified.

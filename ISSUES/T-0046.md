# T-0046 — Run detail and results API

## Report

EPIC-003 SPEC.md §3.3 defines the run detail tabs (Progress, Summary, Findings, Artifacts,
Issues); §6 defines `GET /v1/runs/{runId}` (detail + sections) and
`GET /v1/runs/{runId}/results` (findings summary). §5 keeps `Finding` consumed from EPIC-001,
not re-modelled. The **Issues** tab reads the module's connection/collector error log.

Deliver the detail route returning the run, its `RunSection` rows, and `summaryCounts` (the
pass/fail/warning/review/skipped/not-licensed strip), and the results route returning findings
with cursor pagination. For a parent run, the detail aggregates child runs; per-child detail is
addressable. Tenant-scoped throughout; OpenAPI updated.

## Acceptance

- [ ] `GET /v1/runs/{runId}` returns the run, sections, and summary counts; a parent run
      aggregates its children.
- [ ] `GET /v1/runs/{runId}/results` returns paginated findings and the issue log.
- [ ] A run for a tenant outside the caller's scope is refused.
- [ ] The OpenAPI document matches the implementation.
- [ ] No file outside `scope` is modified.

# T-0949 — A missing ActiveDirectory module logs one identical issue per collector

## Report

Run `b4d11871-d1c2-4857-8b91-b7c79282af21` has four identical WARNING issues:

> Section: ActiveDirectory. Prerequisite not met. The ActiveDirectory module is not installed.
> Install RSAT or run from a domain controller.

- `Invoke-M365Assessment.ps1` (around lines 1444-1454) handles a `not installed` error per
  collector, so each of the four AD collectors throws the same error and adds the same issue.
- The portal worker host has no RSAT, so the ActiveDirectory section cannot run from the
  portal; the section is still offered in `NewRunDialog.tsx`.
- The four issues count toward the run's 11 issues and make the run partial, which hides the
  issues that need action.

## Fix direction

- Check the AD prerequisite once per section; when it is missing, skip the section's collectors
  with a single issue for the section.
- In the portal, disable the ActiveDirectory section (with a short reason) when the worker host
  cannot run it, or treat the skip as the operator's choice like `-SkipPurview`.

## Acceptance

- [ ] A run without the AD module records one ActiveDirectory issue, not one per collector.
- [ ] The portal does not offer a section its worker cannot run, or labels it as unavailable.
- [ ] Tests cover the single-issue behaviour, and fail without the change.

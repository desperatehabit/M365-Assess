# T-0706 — Custom test CRUD, versions, and enable/disable API

## Report

EPIC-036 SPEC.md §6 defines `GET`/`POST`/`PATCH`/`DELETE /v1/custom-tests`,
`GET`/`POST /v1/custom-tests/{id}/versions`, and §3.2 row actions `Edit`, `View versions`,
`Enable/Disable test`, `Enable/Disable alerts`, `Delete`. §7 gated custom-test authoring as a high
privilege, `tests.write` (RBAC owned by EPIC-038). §5 requires versions to be immutable.

Deliver `routes/custom-tests.ts`: CRUD, version listing and append (validating parameters via
T-0705), enable/disable of the test and of alerts, and delete — each writing an `AuditEvent` and
enforcing the `tests.write` seam by contract (stubbed in tests). Update `portal.v1.yaml`. Sandbox
execution and alert delivery are separate tickets.

## Acceptance

- [ ] CRUD, version append, and enable/disable endpoints are implemented and match the OpenAPI document.
- [ ] Saving content creates a new immutable version and repoints `currentVersionId`.
- [ ] Invalid parameters are rejected against the T-0705 schema.
- [ ] Every mutation writes an audit event.
- [ ] No file outside `scope` is modified.

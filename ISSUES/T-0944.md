# T-0944 — A partial or failed run is rendered as 100% and "Completed"

## Report

The portal presents a run that errored as a clean completion.

- The dashboard query treats `partial` as a completed run: `portal/db/src/dashboard-repository.ts:277-287` selects runs with `status IN ('succeeded', 'partial')` for the Latest Assessment payload.
- `portal/web/src/components/dashboard/AssessmentCard.tsx:95-99` always renders `Completed {finishedAt}`, ignoring `assessment.status` even though the widget receives it (`AssessmentCard.tsx:21-27`).
- `portal/web/src/components/RunsTable.tsx:87-103` turns any non-`running`/non-`queued` status, including `partial` and `failed`, into 100%, so the bar also says complete.
- `portal/bff/src/adapters/runs.ts:563-574` marks a section `failed` when its collectors are a mix of `Complete` and `Skipped` (`allComplete` false, `allSkipped` false). Run `b4d11871-d1c2-4857-8b91-b7c79282af21` shows Collaboration as failed even though its only non-complete collectors were the app-only Teams ones, which reported Skipped.
- Observed 2026-11-23: run `b4d11871-d1c2-4857-8b91-b7c79282af21` is `partial` with 11 issues, including one `ERROR` (Power BI Fabric `/admin/tenantsettings` 403). `GET /v1/dashboard/91a2756e-dd8c-4436-a7e2-15f24201499c` returns `assessment.status = "partial"`, yet the Latest Assessment card reads "Completed 23 Nov, 15:28". This is the "it says done but it errored" report.

## Fix direction

- `AssessmentCard`: render status-aware text — `Completed` only for `succeeded`; `Completed with issues` for `partial`; `Failed` for `failed`; include the issue count and a link to the Issues tab.
- `RunsTable`: only return 100% for a succeeded run. For `partial`/`failed`, derive the fraction from sections and show the terminal state; never paint a failed run as full.
- Add a section-level `partial` (or `completed with skips`) state: mixed Complete+Skipped collectors should not read as `failed`; reserve `failed` for a collector that failed or produced no usable output.
- Dashboard: keep `partial` runs eligible for the latest-assessment card, but carry and display the status and issue count; do not call them completed.
- Run detail: show the same status words and counts so the Runs list, dashboard, and run detail agree.

## Acceptance

- [ ] A `partial` run is not labeled `Completed` in the dashboard or Runs list.
- [ ] A `failed` or `partial` run does not render as a 100% bar unless every requested section actually succeeded.
- [ ] A section with Complete and Skipped collectors shows `partial`/`completed with skips`, not `failed`.
- [ ] The latest run `b4d11871-d1c2-4857-8b91-b7c79282af21` shows `Completed with issues` (or equivalent) and surfaces the Power BI error.
- [ ] Tests cover the label and percentage for `succeeded`, `partial`, and `failed`, and fail without the change.
- [ ] No file outside `scope` is modified.

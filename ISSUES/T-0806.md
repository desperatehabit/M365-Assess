# T-0806 — Copilot settings with standards-style apply

## Report

**PARKED / optional.** EPIC-041 is deferred behind EPIC-038; this ticket is authored so the seam
is named.

EPIC-041 SPEC.md §3.3, §4, §8: **Copilot Settings** shows tenant Copilot configuration and
applies changes in a standards-style flow. Settings changes are **tenant writes** and route
through the **EPIC-006** boundary (T-0101) with a plan preview, explicit confirmation,
before/after capture, and audit. `integrations.manage`/admin (T-0743) gates the apply. Reads use
Graph; writes use only the Copilot settings the portal app is permitted to change, failing
closed otherwise.

## Acceptance

- [ ] The page renders current Copilot settings read from the tenant.
- [ ] Apply produces a plan before any write, routes through the EPIC-006 boundary, and captures before/after.
- [ ] The apply requires admin and is audited.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

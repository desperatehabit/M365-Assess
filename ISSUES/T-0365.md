# T-0365 — Defender setup wizard UI

## Report

EPIC-019 SPEC.md §3.2 defines the **Defender Setup** `Wizard`: select policy areas, choose the
target scope, review the plan, then apply, with a **Save as Intune templates** option. §11.4 is
resolved so saving as templates is an **optional toggle, default off**.

Deliver the `DefenderSetupWizard` component: a stepper for area selection → scope → plan preview →
apply, the save-as-template toggle (default off), and result rendering with per-area success/failure.
It posts to the T-0364 deploy route and shows the conflict/overwrite option when the plan reports
existing policies. Kit tokens only.

## Acceptance

- [ ] The wizard selects policy areas and scope and shows the plan before apply.
- [ ] The "Save as Intune templates" toggle defaults off and is passed through to the deploy call.
- [ ] Conflicts surface the overwrite option from the plan.
- [ ] Component tests cover the stepper, toggle default, and result rendering and fail without them.
- [ ] No file outside `scope` is modified.

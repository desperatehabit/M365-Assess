# T-0642 — Licence consumption report API and worker

## Report

EPIC-033 SPEC.md §3.1 defines the **Licences** page: SKU, Enabled, Assigned, Available,
Utilization %, and Monthly cost (if pricing is set), with a utilization bar. §4.1 says the report
reads subscribed SKUs and assignments from Graph and computes consumption; pricing (if set) adds
cost. §6 exposes `GET /v1/tenants/{id}/licenses`. Tenant auth is Graph `Organization.Read.All`
(SPEC §7). The module already resolves tenant licences (`Resolve-TenantLicenses`,
`licensing-overlay.json`); this ticket reads the equivalent Graph data in a worker.

Build the `Get-LicenseReport.ps1` worker job + `get-license-report.ps1` entrypoint that returns
per-SKU enabled/assigned/available/utilization and joins pricing from T-0641 (global seed with
per-tenant override). A SKU with no pricing returns "no pricing" rather than a zero cost (SPEC §9
risk "pricing staleness"). The BFF route validates RBAC (`licenses.read`) and tenant scope and
returns the rows. Extend `portal.v1.yaml`.

## Acceptance

- [ ] The endpoint returns per-SKU enabled/assigned/available/utilization from Graph.
- [ ] Monthly cost reflects the effective pricing row; an unpriced SKU reports "no pricing",
      never a fabricated zero.
- [ ] A tenant outside the caller's scope is refused.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

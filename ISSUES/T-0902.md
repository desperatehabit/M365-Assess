# T-0902 — Implement the webhooks system timer (Graph subscription renewal)

## Report

T-0876 found that the `webhooks` system timer (`portal/bff/src/scheduler/system-timers.ts`)
names `Invoke-WebhookRenewal`, which no worker or runner implements. It used to be enqueued as a
`report` job that no runner could execute, so every tick threw 501. T-0876 marked it
`unavailableReason`, so it is now listed as disabled and skipped.

Implement renewal: for each tenant, list its Graph change-notification subscriptions and renew those close to expiry through `portal/workers/manage-webhooks.ps1` (`-Action renew`), recreating any that have lapsed. Record failures so EPIC-032 surfaces them.

Then remove `unavailableReason` from the timer so the tick runs it again.

## Acceptance

- [ ] The behaviour described in the report is implemented and the timer runs on its cron.
- [ ] A test covers the timer's run and fails without the fix.
- [ ] No file outside `scope` is modified.

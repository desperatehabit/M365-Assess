# T-0952 — DEFENDER-ZAP-001 reports NotLicensed because it reads Teams ZAP from the wrong policy

## Report

- `DefenderPresetZapChecks.ps1` (around lines 94-115) reads `ZapEnabled` from
  `Get-AtpPolicyForO365`. That object has no `ZapEnabled` property, so the check always falls
  through to `NotLicensed` with "Property not available on current license".
- Teams ZAP is `ZapEnabled` on `Get-TeamsProtectionPolicy`.
- Observed on the live tenant, which has Defender for Office 365 Plan 2 (`THREAT_INTELLIGENCE`):
  `Get-TeamsProtectionPolicy` returns `ZapEnabled: True` for the default Teams protection policy.
  The run reported `NotLicensed`.

## Fix direction

- Read `Get-TeamsProtectionPolicy` (`ZapEnabled`); Pass when true, Fail when false.
- Report NotLicensed only when the cmdlet is unavailable or the tenant lacks the Defender for
  Office 365 plan, not when a property is missing.

## Acceptance

- [x] A tenant with Teams ZAP enabled reports Pass with `ZapEnabled: True`.
- [x] Tests mock `Get-TeamsProtectionPolicy` and fail without the change.

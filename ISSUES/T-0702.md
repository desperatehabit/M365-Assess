# T-0702 — TestPack and TestRun schema and repository

## Report

EPIC-036 SPEC.md §5 defines `TestPack` (`id`, `name`, `description`, `checkIds[]`/`frameworkId`,
`scoring`) and `TestRun` (`id`, `packId`/`testId`, `tenantId`, `at`, `score`, `results[]`) as the
report source. ADR-0015 requires numbered, forward-only migrations behind the repository interface.

Deliver migration `0105_test_packs.sql` (next free global number) creating both tables, plus
repository methods on `repository.ts`/`sqlite-repository.ts` to persist/read packs and test runs
(tenant-scoped), storing `results` as a serialized JSON payload referencing finding rows rather
than duplicating them. The catalogue and scoring live in T-0701; this ticket only persists their
output. Audit events for test changes are written through the existing `AuditEvent` store.

## Acceptance

- [ ] Migration `0105` applies after the latest migration, is re-runnable, and advances `SchemaVersion`.
- [ ] The repository persists and reads TestPack/TestRun; no raw SQL appears outside `portal/db/`.
- [ ] TestRuns are tenant-scoped and scoped queries cannot cross tenants.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

# T-0627 — Manual search and saved searches UI

## Report

EPIC-032 SPEC.md §3.1 defines the **Manual Searches** page: a filter form (date range, user,
activity, workload, IP) and a results table with columns Timestamp, User, Activity, Workload,
Object, Result, and row actions `View detail`, `Export CSV`, `Save search`. §3.2 defines the
**Saved Log Searches** table with `Run`, `Edit`, `Schedule`, `Delete`. Nav is *Tenant
Administration → Audit Logs*.

Build the routes and `ManualSearchForm` / `SavedSearchesTable` components plus a typed
`auditApi.ts` client for the T-0622 search and T-0623 saved-search endpoints. Use the shared
DataTable, badge, and ActionDialog components and report theme tokens only; no colour literals.
Export CSV routes through the T-0622 export path so the access is audited.

## Acceptance

- [ ] The manual search form applies the §3.1 filters and renders every result column.
- [ ] `View detail`, `Export CSV`, and `Save search` are wired; the saved-searches table exposes
      all four row actions.
- [ ] A test covers the component states and fails without it; only theme tokens are used.
- [ ] No file outside `scope` is modified.

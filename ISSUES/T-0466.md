# T-0466 — Historical Search page with progress, cancel, and download

## Report

EPIC-024 SPEC.md §3.2 fixes the page title **Historical Search**: scoped search parameters, a
results list of matching messages, a download option for permitted callers, and long-running
searches that show progress and are cancellable. Nav follows *Tools → Email Tools* per §3;
styling uses report theme tokens only.

Deliver the historical-search route rendering `HistoricalSearchForm` and
`HistoricalSearchResults` against the T-0465 API, with a live progress indicator, a cancel
action, and a download affordance shown only when the caller holds the download permission. A
Vitest/Testing-Library test covers idle, running (progress), cancelled, completed, and
permission-gated-download states.

## Acceptance

- [ ] Starting a search renders progress from the job's events; cancel stops it.
- [ ] The download affordance renders only for permitted callers.
- [ ] Idle, running, cancelled, completed, and gated states are tested; only tokens are styled.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

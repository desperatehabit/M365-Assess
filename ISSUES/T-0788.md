# T-0788 — Breach lookup provider seam (deferred to EPIC-041)

## Report

EPIC-040 SPEC.md §3.4, §4.3, §6 (US-5) and §11 open question 2. This item is **Deferred:** the
HIBP/breach data integration belongs to **EPIC-041** (T-0801 framework; a breach/HIBP adapter is
not trivially available and stays parked). This ticket therefore delivers only the pluggable
provider seam, not a live data source.

Build `breach-lookup-service.ts` around a `BreachProvider` interface and enforce that
`POST /v1/breach-lookup` fails closed with a structured "integration not configured" error when
no provider is registered. The service requires `CIPP.Admin.*` and audits every query for
privacy (§7, §9); account/tenant identifiers must never be written to logs in cleartext beyond
the audit record. When EPIC-041 later registers a provider, no route or page change is needed.
No page is shipped in this ticket.

## Acceptance

- [ ] `POST /v1/breach-lookup` returns a structured "integration not configured" error when no provider is registered.
- [ ] The query path is admin-gated and writes a privacy-preserving `AuditEvent`.
- [ ] The `BreachProvider` interface is documented and unit-tested with a fake provider.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

# T-0408 — Transport rule and connector template UI with deploy

## Report

EPIC-021 SPEC.md §3.3 fixes the UI: page titles **Transport Rule Templates** and **Connector
Templates**, each with `View`, `Edit`, `Clone`, `Deploy`, `Export`, `Delete`; **Deploy shows a
plan and supports variable substitution** (domains, IPs). §4.2 requires the deploy plan to show
the resolved rule/connector JSON and report partial failures.

Deliver the Next.js pages above using the template CRUD APIs (T-0403, T-0405) and the deploy route
(T-0406): the template list and editor, the variable-substitution form, the deploy plan preview,
and the per-target result view. Export produces the template JSON locally. No browser call reaches
a tenant directly.

## Acceptance

- [ ] Rule and connector template pages render with the §3.3 row actions from the BFF.
- [ ] Deploy collects variables, shows the resolved plan, and displays per-target results including partial failures.
- [ ] Export produces the template JSON without a tenant write.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

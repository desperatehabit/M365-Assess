# T-0662 — Domain inventory API and worker

## Report

EPIC-034 SPEC.md §3.1 defines the **Domains** page: Domain, Type (initial/verified/managed),
Verification, DNS health badge, Services (MX target), Last checked. §4.1 says domains are listed
from Graph. §6 exposes `GET /v1/tenants/{id}/domains`. Tenant auth is Graph `Domain.ReadWrite.All`
for domain ops (SPEC §7). The most recent DNS health and last-checked come from the T-0661
`DomainCheck` history.

Build the `Get-DomainInventory.ps1` worker job + `get-domains.ps1` entrypoint that reads the
tenant's domains from Graph and joins the latest stored DNS health per domain, and the BFF route
that validates RBAC (`domains.read`) and tenant scope and returns the rows. The
`.onmicrosoft.com` handling is a DNS-analysis concern (T-0664) and is not applied to the inventory
list. Extend `portal.v1.yaml`.

## Acceptance

- [ ] The endpoint returns every domain with its type, verification state, MX target, and the
      latest stored DNS health/last-checked where available.
- [ ] A domain with no stored check returns an empty last-checked/DNS state, not an error.
- [ ] A tenant outside the caller's scope is refused.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

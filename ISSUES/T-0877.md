# T-0877 — Standards catalog tenant license classification returns 501

## Report

`portal/bff/src/app.ts:757-760` mounts the catalog with
`resolveTenantLicense: unavailableTenantLicenses`, which throws the
`standards.license.unavailable` 501 response (`portal/bff/src/adapters/standards.ts:40-46`). As a
result `GET /v1/standards/catalog?tenantId=...` fails whenever a position needs license
classification (T-0828), and the picker cannot show the `license missing` state (EPIC-008 SPEC §6,
§4.4). The no-tenant catalog works.

## Fix direction

Resolve the tenant's purchased/available service plans (the EPIC-033 licensing providers expose SKU
data) and feed them to the catalog classifier instead of `unavailableTenantLicenses`.

## Acceptance

- [ ] `GET /v1/standards/catalog?tenantId=...` returns 200 with per-check license classification.
- [ ] The picker shows `license missing` for checks the tenant cannot run.
- [ ] A test covers a tenant with a partial license set and fails without the fix.
- [ ] No file outside `scope` is modified.

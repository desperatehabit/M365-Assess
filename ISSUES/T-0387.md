# T-0387 — Retention policies, tags, and assignment

## Report

EPIC-020 SPEC.md §2 (US-7), §3.6, §4.4, §5, and §6 require listing retention policies and tags,
creating/editing tags, and assigning them to mailboxes. Resolved §11.3 adopts **both per-mailbox
and bulk assignment**. §4.4 requires the assignment preview to show which mailboxes are affected
before apply.

Deliver migration `0033_retention_tags.sql` for the optional local `RetentionTagAssignment`
record and `retention-repository.ts`. Add `retention.ts` for the §6 `GET`/`POST` routes and the
`Set-RetentionTag.ps1` worker job plus `set-retention-tag.ps1` entrypoint. Both single and bulk
assignment route through the EPIC-006 gate (T-0107); the plan preview lists affected mailboxes;
each write records before/after, a `MailboxOperation` (T-0382), and an `AuditEvent`. Policies and
tags themselves are read live from EXO. Tenant and credential records are EPIC-002 (prose
dependency).

## Acceptance

- [ ] Retention policies and tags list; tags create and edit.
- [ ] Per-mailbox and bulk assignment both work, and the preview lists affected mailboxes before apply.
- [ ] Every assignment routes through the EPIC-006 gate and writes an `AuditEvent`.
- [ ] A test covers the change and fails without it.
- [ ] No file outside `scope` is modified.

# T-0804 — PSA/RMM vendor adapter (deferred)

## Report

**PARKED / deferred.** EPIC-041 SPEC.md §1, §2 (US-1), §3.1, §9. The PSA/RMM connectors
(Halo, Hudu, NinjaOne) are **deferred** until demand names a specific vendor; no vendor is
selected, so this ticket is optional and stays behind the parked epic.

Deliver the vendor-neutral `psa-adapter.ts` shape through the T-0801 registry: entity mapping
config, a `test` handshake, and a `sync` entry point that is a no-op until a concrete vendor
adapter is registered. All sync runs are scheduled by EPIC-007 and alert on failure (§4). No
vendor-specific HTTP is added in this ticket; the interface and its contract test are the
deliverable so a later vendor adapter is a small addition.

## Acceptance

- [ ] The PSA adapter interface registers with T-0801 and exposes mapping config, test, and sync.
- [ ] Sync is a no-op with a structured "no vendor configured" result until an adapter is registered.

- [ ] A contract test exercises the interface with a fake vendor.

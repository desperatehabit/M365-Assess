# T-0605 — Peer comparison API with graceful absence

## Report

EPIC-031 SPEC.md §2 US-3 and §3.3 define peer comparison against *similar organisations* and *all
organisations* where Microsoft provides the comparison data. §6 fixes `GET
/v1/tenants/{id}/secure-score/peers`. §11.3 is resolved to resolve the peer fields from Graph
`secureScores` **with graceful absence**, and §9 warns that when Microsoft returns no comparison
data the view must render nothing rather than an error.

Deliver the peers route, extending the T-0602 read to surface the comparison fields from the Graph
`secureScores` response. When the comparison fields are absent, return an explicit
`available: false` result with no synthetic benchmark; never fabricate peer data.

## Acceptance

- [ ] `GET .../secure-score/peers` returns similar-organisation and all-organisation comparisons when present.
- [ ] When Graph omits the comparison fields, the response reports unavailability without an error.
- [ ] No peer value is invented when Microsoft provides none.
- [ ] A test covers present and absent comparison data and fails without the code.
- [ ] No file outside `scope` is modified.
